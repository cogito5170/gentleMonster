# P1 — 가진 재료로 만드는 방향 (제안)

작성일: 2026-10-21. 상태: **제안 — 사용자 확인 전.**

## 조건 (사용자, 2026-10-21)

1. 이미지 파일은 세 가지뿐이다: **직접 찍은 사진 · 나의 패션 사진 · 건축학과 작업물.**
2. 텍스트로 많이 채울 수 없다.
3. VMD 직군의 결과물(실제 진열 · 시공 · 매출)을 적을 수 없다.

## 지금 P1 목차(p1_types.md §3)와 부딪히는 곳

목차 12쪽 중 **9쪽이 지금 없는 재료**에 기댄다.

---

## 방향: 세 재료 = VMD 의 세 능력

확정된 세 요소(조합하다 · 비추다 · 짓다, W2-D19)가 가진 재료 세 가지와 **하나씩 맞는다.**

| 재료 | VMD 의 일 | 이 재료가 보여 주는 것 |
|---|---|---|
| **건축학과 작업물** | **짓다** — 공간에 맞게 세운다 | 평면 · 단면 · 모형으로 공간 · 동선 · 스케일을 다룰 줄 안다 |
| **직접 찍은 사진** | **비추다** — 볼 곳을 정한다 | 무엇 앞에서 멈추는지, 빛 · 프레임 · 한 점을 볼 줄 안다 |
| **나의 패션 사진** | **조합하다** — 여러 아이템의 합을 만든다 | 색 · 실루엣 · 소재를 고르고 합칠 줄 안다 (나를 진열해 왔다) |

책이 말하는 것: **"VMD 결과물은 아직 없다. 대신 VMD 가 하는 세 가지를, 나는 다른 재료로 이미 해 왔다."**
결과를 주장하지 않고, **능력을 이미지로 증명한다.**

### 결과물 대신 — "VMD 의 눈으로 다시 읽기" 표시

글 대신 **내 이미지 위에 VMD 의 말로 짧은 표시**를 얹는다. ETÉREO 의 DETAIL 면(`a)` `b)` 표지 · 짧은 캡션)과 같은 방식이다.

- 건축 도면 위에: *Zoning* · *Circulation* · *Eye level* · *Scale* — 동선 화살표, 눈높이 선
- 사진 위에: *Focal point* · *Repetition* · *Contrast* · *Light* — 시선이 처음 닿는 곳에 작은 원, 반복되는 것에 같은 번호
- 패션 사진 위에: 색 비율 띠, 아이템 이름, *Triangle*(삼각 구성) · *Rhythm* — 실루엣 선
- 표시는 가는 선 + 산세리프 낱말 하나. 문장을 쓰지 않는다.

이 표시가 "VMD 를 안다"를 문장 없이 보여 준다. 수치는 재료에서 직접 잴 수 있는 것(도면 치수)만 쓴다.

### 글자 예산

| 어디 | 얼마나 |
|---|---|
| 이야기 단락 A (확정) | 책 전체에서 **한 번**, 1쪽 리드 문단으로 |
| 장마다 | 영문 제목 한 낱말 + 국문 한 문장 |
| 표시 · 캡션 | 낱말 하나씩 |
| 합계 | 문장 10개 안팎 |

ETÉREO 의 타입 중 긴 본문이 필요한 **TEXT · TITLE-c 는 쓰지 않는다.** 나머지 아홉(OPEN · TITLE-a · TITLE-b · TIME · HEADLINE · COLLAGE · GRID · DETAIL · ECHO)은 모두 사진 · 제목 · 짧은 캡션만으로 선다.

## P1 목차 — 가진 재료로 (안)

ETÉREO 의 흐름(p1_story_flow.md)을 그대로 쓴다: **멀리에서 가까이로** — 공간(건축) → 장면(사진) → 몸(패션).
이 순서는 VMD 의 순서와도 같다: 매장 공간을 나누고 → 창 하나의 장면을 만들고 → 마네킹 한 벌을 입힌다.

| 쪽 | 장 | 타입 | 재료 | 내용 |
|---|---|---|---|---|
| 표지 | — | (OPEN 형) | 사진 1장 *또는* 지금의 표지 시안 | 아래 '정할 것' 2 |
| 1 | 도입 | TITLE-a | 사진 1장 | From *the* inside. 리드 문단 = 이야기 단락 A (책의 유일한 긴 글) |
| 2 | **장 1 · 짓다** | TITLE-b | 건축 — 모형 사진 | *Build*. 한 문장 + 오른쪽 모형 사진 전면 |
| 3 | | COLLAGE | 건축 — 평면 · 단면 · 모형 | 크기 다른 3장, 이탤릭 캡션 제목 *Zoning* · *Circulation* · *Eye level*, 도면 위 표시. 흑백 |
| 4 | **장 2 · 비추다 (가운데)** | OPEN | 사진 — 가장 강한 1장 | 양면 전면, 흰 제목 두 낱말을 접는 선 양쪽으로 |
| 5 | | GRID | 사진 — 7장 + 1장 | 내가 멈춘 장면들. 큰 1장이 나머지를 대표 |
| 6 | | DETAIL | 사진 — 2장 + 클로즈업 1장 | `a)` `b)` 표지: 시선이 닿는 곳 · 빛 · 반복 · 빨간 한 점 |
| 7 | **장 3 · 조합하다** | TIME | 패션 — 전신 1장 + 4장 | 장소 *(요일)* 해 — "그날 갈 장소에 맞춘다". 오른쪽 4장 한 줄 = 다른 날의 나 |
| 8 | | HEADLINE | 패션 — 착장 1벌 | 착장 분해: 큰 사진 + 아이템 라벨 + 벌린 한 줄 `black · olive · beige · grey` |
| 9 | **장 4 · 하나의 창 (제안)** | COLLAGE | 세 재료 + 코드 도면 | 세 능력을 창 하나에: 도면(짓다) · 사진의 빛과 한 점(비추다) · 내 착장을 입힌 마네킹 도식(조합하다). **'제안 · Proposal'** 이라고 쓴다. 넣지 않아도 된다. 레이아웃: [p1_layout/page09_layout.pdf](p1_layout/page09_layout.pdf) |
| 10 | 닫는 면 | ECHO | 앞의 이미지 | 새 이미지 없이 모형 · 사진 · 착장을 다시 섞는다. 머리말 낱말을 흩는다 |
| 뒤표지 | — | (OPEN 형) | 사진 1장 | 이름 · 연락처 `____` |

표지 · 뒤표지 포함 12쪽. 제안(9쪽)을 빼면 11쪽.

### 흐름을 만드는 장치 (p1_story_flow.md 의 문법)

- **가운데가 가장 크다:** 장 2(사진)가 세 펼침면, 4쪽이 유일한 양면 전면.
- **가운데 앞의 대비:** 장 1 은 흑백 도면 · 사람 없음 → 장 2 는 컬러 사진 · 거리 장면. 차가운 공간 다음에 장면이 와서 가운데가 산다.
- **사물 하나로 잇기:** 모형의 창 · 개구부(장 1) → 사진 속 창 · 유리(장 2). 사진 속 한 색(장 2) → 착장의 같은 색(장 3). 어떤 사물로 이을지는 실제 이미지를 보고 고른다.
- **색:** 건축 = 흑백, 사진 · 패션 = 필름 컬러, 제안 · 닫는 면 = 섞임.
- **처음으로 돌아와 닫기:** 닫는 면에서 1쪽의 사진을 다시 쓴다.

### 하지 않는 것

- VMD 현장 사진 · 신세계 창 사진을 내가 한 일처럼 쓰지 않는다.
- 생성 이미지를 실제 시공 · 진열 결과처럼 보이게 쓰지 않는다. 제안은 도면 · 도식으로만, '제안'이라고 적는다.
- 재료에서 확인할 수 없는 수치(매출 · 유입 · 관찰 수)는 쓰지 않는다.

## 정할 것

1. 이 방향(세 재료 = 세 능력, 공간 → 장면 → 몸)으로 P1 목차를 바꿀지. 바꾸면 p1_types.md §3 을 이 표로 대신한다.
2. **표지:** 지금 시안(미드저니 생성, W2-D20 · D21)을 쓸지, 직접 찍은 사진 한 장으로 바꿀지. 책 안이 모두 내 이미지라면 표지도 내 사진인 쪽이 일관된다.
3. **제안 쪽(9쪽)을 넣을지.** 넣으면 도면 · 도식은 저장소의 청사진 도구로 그린다.
4. **재료 받기:** 세 재료의 이미지를 보내 주면 쪽마다 들어갈 이미지를 고른다. 필요한 것 — 사진 15장 안팎, 패션 사진 5–8장(전신 포함), 건축 작업(모형 사진 · 평면 · 단면).
