## 원칙 (모든 단계)

| 구분 | 규칙 |
|---|---|
| 출처 | 출처 없는 회사 사실 · 대표 발언은 쓰지 않는다. 출처마다 확인 수준을 단다: ✅ 1차 (공식 사이트 · 공식 보도 · 사용자 캡처) / 🔎 검색 요약만 (원문 미확인) / ⛔ 접속 불가. |
| 수치 | 기사마다 다른 수치는 쓰지 않거나 범위로만 적는다. |
| 동기 | 지원 동기 · 관심 · 방문 경험은 지어내지 않는다. 없으면 사용자에게 묻는다. |
| 본 것과 읽은 것 | 매장을 직접 본 것과 기사로 읽은 것을 나눈다. 본 적 없는 매장의 연출을 '봤다'고 쓰지 않는다. |
| 해석 | 사실과 해석을 다른 칸에 둔다. 해석은 '해석' 이라고 적는다. |
| 결정권 | 단계마다 사용자가 고른다. 분석은 고를 거리를 내놓는 데서 멈춘다. |
| 분쟁 | 회사를 둘러싼 분쟁 · 논란은 따로 적고, 다룰지는 사용자가 정한다. |

## 단계

| 단계 | 하는 일 | 나오는 것 | 사용자 | 처음 쓴 곳 |
|---|---|---|---|---|
| **K0 공고 원문** | 공고를 그대로 옮겨 적는다. 사이트에 못 들어가면 사용자에게 캡처를 받는다 | `postings` 또는 `01_scope_posting.md` 앞부분 | 캡처 제공 | SI |
| **K1 대상 · 범위** | 채용 회사 · 브랜드 · 모회사의 관계 (소속 · 파견 · 협력사), 기간 (기본 최근 3년), 관점 = 지원 직무가 보는 것 (공간 설계 → 공간 전략, 라운딩 VMD → 매장 · 진열 전략) | `01_scope_posting.md` | 확정 | B1 |
| **K2 공고 해부 · 적합도** | 담당 업무를 축으로 나누고, 자격 · 우대에서 되풀이되는 낱말에 무게를 둔다. 요구마다 사용자 사실 근거와 판정 (충족 · 부분 · 공백 · 확인 필요). 이미 쓴 다른 회사 지원서에서 그대로 쓸 것 · 바꿀 것 | `01_scope_posting.md` | 공백 사실 답하기 | CMD-HJ44 |
| **K3 자료 수집** | 공식 채널 (홈페이지 브랜드 스토리 · 보도자료) 먼저, 그다음 기사 · 매거진 · 영상. 날짜 · 매체 · 내용 · 확인 수준 · 신뢰도 표 | `02_sources.md` | 자료 더하기 · 고르기 | B2 |
| **K4 발언 · 키워드 · 사례** | 대표 · 관계자 직접 인용, 되풀이되는 키워드, 매장 · 캠페인 사례 | `03_keywords_cases.md` | 인상 깊은 것 고르기 | B3, GM ① |
| **K5 분석** | 방향성 / 이미지 / 가치관 / 직무 관점 전략 (공간 · 매장 · 진열). 필요하면 방향이 비슷한 브랜드와 비교 (GM ②), 포트폴리오용이면 이론 틀 (GM ③) | `04_analysis.md` | 해석 확인 | B4, GM ②③ |
| **K6 '왜 이 회사 · 이 자리' 답변 유형** | 4~6개 유형: 논리 한 줄, 쓰는 사용자 사실, 쓰는 회사 사실과 확인 수준, 면접 반문 위험, 납득도. 추천 1~2개 | `04_analysis.md` | 고르기 | CMD-HJ85 |
| **K7 사용자 연결** | 회사 가치와 사용자 경험 · 지향의 겹침과 차이. 직접 방문 · 이용 경험을 받는다. 사용자가 자기 관점으로 요약하면 그대로 기록 (예: 에르노 기사 → '도전성') | `05_user.md` | 경험 · 관점 더하기 | B5, SI 에르노 |
| **K8 결과물** | 한 장 요약, 자기소개서 근거 (쓸 수 있는 사실과 확인 수준), 포트폴리오 재료, 면접 예상 질문, **쓰면 안 되는 미확인 사실 목록** | `05_user.md` 끝 → 확정되면 `06_summary.md` | 확정 | B6 |
