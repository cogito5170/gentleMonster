## K5 분석 (관점: 공간 오브제)
| 축 | 사실 | 해석 |
|---|---|---|
| **방향성** | 파리 · 쿠알라룸푸르 · 두바이 · 싱가포르 · 뉴욕으로 플래그십 확장과 리뉴얼 (G3~G8) | 같은 상징 오브제 (Giant Head)를 도시마다 다시 세우고, 새 버전 (Glossy Head)으로 갱신 → 오브제가 **브랜드의 얼굴** |
| **이미지** | 미학 + 예측할 수 없는 발상 (✅), 하이퍼리얼 · 키네틱 (G5), 목가 · 유머 (G7 · G8) | 아름답지만 낯설고, 무섭지 않게 엉뚱한 |
| **가치관** | 세상을 놀라게 하라, 어디에도 없는 공간, 공간 = 세계관 경험 (G2) | 매장의 목적은 '놀라움을 겪게 하는 것' |
| **오브제 전략** | 매대 대신 대형 설치 (G2), 사내 로보틱스 랩 (G3), 시즌 컬렉션과 묶인 팝업 오브제 (G7) | 오브제팀 = 컬렉션 · 공간 · 기술을 한 물체로 묶는 팀. 제작까지 맡음 |
| **사용자 경험 (✅)** | 홍대: 오브제가 발걸음을 안으로 이끔, 계단이 전시의 연장 (G11) | 오브제는 '보는 것' 이자 **동선을 이끄는 장치** |
