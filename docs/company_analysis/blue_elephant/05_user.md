## K8 결과물 (캡처 · 답을 받은 뒤 확정)
- **자기소개서 근거**: 공고 문구 (✅) 를 먼저 — '다양한 분야에서 얻은 영감을 현대적으로 재해석', '차별화된 공간과 고객 경험', '현재에 머무르지 않습니다'. 캠페인 · 매장 사실은 캡처 뒤에.
- **포트폴리오 재료** (공고: 포트폴리오 필수, 비주얼 콘텐츠 인턴): 사진 작업, 공간을 찍은 장면, 썸네일 · 상세페이지 · 배너 형식의 시안 (블루엘리펀트 제품을 가정해 만들지는 사용자 결정), 아카이빙 방식.
- **면접 예상 질문**
  1. 우리 매장 (성수 · 홍대 등)에 가 봤나요? 무엇을 찍고 싶었나요?
  2. 우리 상세페이지 · 인스타그램에서 바꾸고 싶은 것은?
  3. 최근 본 캠페인 중 좋았던 것과 이유는?
  4. 스페이스 성수를 한 장의 피드 이미지로 만든다면?
  5. Photoshop · Illustrator 로 어디까지 할 수 있나요? 영상은?
  6. AI 툴을 어떻게 써 봤나요?
  7. 건축 전공인데 왜 비주얼 콘텐츠 인턴인가요? 3개월 뒤에는?

## 쓸 수 있는 것 (✅)
- 공고 · 채용 홈 문구: '상상가 (Imagineer) … 상상을 현실로', '다양한 분야에서 얻은 영감을 현대적으로 재해석', '현재에 머무르지 않습니다'.
- 뉴스1 (2025-10-02): '아이웨어를 단순한 패션 아이템이 아닌 문화적 경험으로 재해석', '누구나 어디서든 쉽고도 특별하게'.
- 패션비즈: 스페이스 2.0 '터널 · 구조 · 장면'.
- 세계일보: 하라주쿠 '층마다 독창적인 인테리어', '쇼핑 이상의 경험'.
- 이코노미스트: 디자인센터 신설 · 조직 고도화, 4만~6만 원대.
- 공식 몰 · 상세페이지 구성 (직접 본 화면).

## 쓰면 안 되는 것
- 매출 · 영업이익 · 부채비율 · 매장 수 · 스페이스 성수 규모 (800평 / 1,000평 / 3,300㎡ — 매체마다 다름).
- 디자인 분쟁과 그에 얽힌 서술 (UQ6), 대표 이름 (캡션 판독 불확실).

## 답으로 바뀐 것
- **매장 관찰 = 스페이스 2.0 과 그대로 겹친다**: '장식 요소를 빼고 건축 구조로 제품과 고객에게 주목을 모은다' (C13) ↔ H빔 골조 · 노출콘크리트 · 오브제 같은 매대. '장면 = 안경을 쓰고 사진을 찍는 공간' (C13) ↔ 거울이 많아 바로 확인 → 편함 → 구매. **사용자 본인이 공간 → 경험 → 소비를 겪은 직접 근거.** A (장면 · 멈춤형) 와 B (공간을 화면으로) 를 합칠 수 있다.
- 추천 답변 (확정 전): **D 다방면 비주얼 (패션 · 사진 · 건축 + 영어 리서치 · SNS) → A+B 매장 경험 (구조가 보이는 공간, 거울로 바로 확인, 구매까지) → C 정리 · 체계 한 문장 → E AI 적극 활용 · 새 툴은 빠르게 익힘**.
- 영상 툴은 '써 봤다' 고 쓰지 않는다. '다양한 프로그램을 써 와서 빠르게 익힌다' 로만.
