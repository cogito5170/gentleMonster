## 지금 상태

- **글은 아직 템플릿 자리 글이다.** "Grid Systems 001", "© 2026 Template.Systems", "download now www.template.systems", "column grids (multiple vertical columns)" 등은 모두 Template.Systems 템플릿의 문구다. 최종본에 남으면 안 된다.
- **v1 에서 달라진 것**
  - 섹션 첫 장이 글 대신 큰 제목(STYLE)으로 열린다.
  - 사진이 커졌고, 접힘을 넘어가는 사진(한강)이 생겼다.
  - 배경이 연한 올리브 대신 흰색 → 형광 노랑이다.
  - v1 의 한국어 본문, 영어 질문 제목, 캡션은 아직 안 들어왔다.

## 흐름 (지금까지)

```
표지   SPA · Where Did You Last Stop?
A      STYLE 큰 제목 (001)
B      스타일 사진 세 장 + 글 자리
C      웹 디자인 DAILY LookBook
D      풀쿼트 펼침  STYLE → PICTURE 다리
E      MOMENT LIKE A PHOTOGRAPH (002) + 여는 글 "그래서 내 두 번째 이야기는 사진이다"
F      카메라를 들면 관찰한다 → 공간도 빛과 사람의 위치에서 시작 · PICUTRE 제목
G      사진 펼침 (글 자리만)
```

- 섹션 제목에 번호가 붙기 시작했다: (002). STYLE 쪽은 아직 템플릿 문구 "Grid Systems 001" 이라 형식이 다르다 → `(001)` 로 맞춘다.
- PICTURE 제목은 커버 문구 "A Moment like A Photograph" 에서 왔다. 같은 규칙이면 STYLE 은 "A Person with Style", ARCHITECTURE 는 "A Building That Holds Me" 에서 제목을 가져올 수 있다.
- v1 의 끊김 2번(웹 디자인이 STYLE 과 풀쿼트 사이에 끼어 있음)이 그대로다. C 와 D 의 순서를 바꾸면 B 의 스타일 글 → D 풀쿼트가 곧장 이어지지만, 그러면 풀쿼트 → PICTURE 사이에 웹이 들어간다. 웹을 STYLE 섹션의 "보여주기"로 두려면 C 첫머리에 이어 주는 한 줄이 필요하다(예: "고르는 눈으로 화면도 만든다").
- v1 PICTURE 여는 글의 "앞 페이지의 사진도 그랬다" 는 이제 D 펼침을 가리키는데, 사이에 E 제목 장이 들어간다 → "앞 펼침의 사진" 처럼 고친다. 바로 위에 기차 사진이 있어서 지금은 "앞 페이지의 사진" 이 기차 사진으로 읽힌다.
- **여는 글에서 "멈춘다" 가 빠졌다.** v1 첫 문장 "두 번째로, 내가 멈추는 곳은 멋진 장면 앞이다." 가 없어지고 "빛, 색, 사람, 장소가…" 로 바로 시작한다. 책 전체를 잇는 동사이자 커버 질문에 대한 답이라 되살린다.
- **한 섹션에 큰 제목이 두 개다.** E 의 MOMENT LIKE A PHOTOGRAPH (002) 로 섹션을 열고, F 에서 PICTURE 가 또 큰 제목으로 나온다. STYLE 섹션은 STYLE 하나뿐이다. 규칙을 하나로: (가) 섹션 첫 펼침 = 커버 문구 제목 + 번호, 섹션 이름(STYLE · PICTURE)은 작은 머리말 / (나) 섹션 이름을 큰 제목, 커버 문구는 부제. STYLE 쪽도 같은 규칙으로 맞춘다.
- **번호가 둘로 읽힌다.** 10쪽 (002) 는 섹션 번호처럼 크고, 12 · 14쪽 (003) 은 작게 붙었다. (003) 이 ARCHITECTURE 번호라면 PICTURE 지면에 있으면 안 되고, 펼침 번호라면 (002) 와 크기 · 위치를 구분한다.
- G 의 글 자리 → v1 9장 **What makes a good picture?** 답: 첫째 오래 보게 되는 사진, 둘째 하나의 이야기가 되는 사진 → "좋은 사진은 생각하게 만들고, 다시 떠오르게 한다". 영어 질문 제목도 STYLE 처럼 붙인다.
- PICTURE 끝에서 ARCHITECTURE 로 넘기는 줄이 아직 없다(v1 끊김 5번). G 또는 그 다음 펼침에 "좋은 사진에는 늘 좋은 장소가 있었다" 같은 다리를 둔다.

## 확인할 것

- 한강 사진이 접힘을 넘어간다. 사람은 4쪽 오른쪽 끝, 접힘 가까이에 있다. 제본하면 접힘에 먹히는 폭만큼 사람이 가려지지 않는지 본다.
- A 의 검정 상자가 한 장의 사진인지, 두 장인지.
- C: MARKET 화면 그림 안의 v1 오류(Material 제목 중복 · Sprite · Chekck · Fliss · Hulis)가 그대로다. 그림 원본에서 고쳐야 한다. 화면이 접힘을 넘어가며 세 번째 열 상품이 접힘에 걸린다.
- C: 모브색 화면이 형광 노랑 위에 놓인다. 배경과 화면 색이 서로 부딪히지 않는지 본다.
- D: 흰 글자가 형광 노랑 위에 있어 대비가 아주 낮다. 마젠타 단어만 읽히는 것이 의도라면 괜찮지만, 문장 전체가 읽혀야 한다면 흰 글자 색을 바꾼다.
- E-10: 왼쪽 아래 "…l now / …plate.systems" 가 잘려서 남아 있다(앞 장에서 넘어온 템플릿 글 상자). 지운다.
- E-11: 제목 "LIKE A" 의 A 가 오른쪽 끝에서 잘린다. 의도한 넘침인지 확인한다.
- E-11 본문 오자: "그리고 그 뒤의 화분과 사람, 장소가 함께 맞아떨어진 순간이었다." → v1 원문은 "그리고 그 뒤의 화분과 칠판. 사람과 장소가 함께 맞아떨어진 순간이었다." (칠판이 빠지고 문장이 붙었다)
- E-11: 기차 사진만 검은 테두리가 있다. 다른 사진은 테두리가 없다 → 하나로 맞춘다.
- **F-13 제목 오타: PICUTRE → PICTURE.**
- F: 흑백 루프탑 사진 위아래에 검은 띠가 있다(사진보다 상자가 크다). 의도가 아니면 상자를 사진에 맞춘다.
- F · G: 접힘을 넘는 사진이 두 장 더 있다(루프탑 · 바다). 바다 사진의 두 사람이 14쪽 오른쪽 끝, 접힘 가까이에 있다.
