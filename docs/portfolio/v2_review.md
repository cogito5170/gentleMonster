## 지금 상태

- **글은 아직 템플릿 자리 글이다.** "Grid Systems 001", "© 2026 Template.Systems", "download now www.template.systems", "column grids (multiple vertical columns)" 등은 모두 Template.Systems 템플릿의 문구다. 최종본에 남으면 안 된다.
- **v1 에서 달라진 것**
  - 섹션 첫 장이 글 대신 큰 제목(STYLE)으로 열린다.
  - 사진이 커졌고, 접힘을 넘어가는 사진(한강)이 생겼다.
  - 배경이 연한 올리브 대신 흰색 → 형광 노랑이다.
  - v1 의 한국어 본문, 영어 질문 제목, 캡션은 아직 안 들어왔다.
