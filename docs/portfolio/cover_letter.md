# 자기소개서 — 젠틀몬스터를 지원한 이유, 왜 젠틀몬스터여야 하는가?

조건: 1000자 이내 · 지원 분야: Gentle Monster 공간 디자인

## 진행 방식

추론으로 한 번에 쓰지 않는다. 1–8단계마다 **지원자가 답을 내고**, 부족하거나 막힌 곳을 함께 보완해 **완성된 답**을 확정한 뒤 다음 단계로 넘어간다.
여덟 단계의 완성된 답을 모두 모은 뒤 1000자 이내 한 편으로 합친다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 문항을 둘로 나눈다 — 지원한 이유 / 왜 젠틀몬스터여야 하는가 | 진행 중 |
| 2 | 내 축을 하나로 정한다 | 대기 |
| 3 | 젠틀몬스터를 '내 말'로 옮긴다 | 대기 |
| 4 | 직접 겪은 장면 하나 | 대기 |
| 5 | '왜 젠틀몬스터여야 하나'를 비교로 증명한다 | 대기 |
| 6 | 내가 가져갈 것 | 대기 |
| 7 | 구조와 분량 | 대기 |
| 8 | 퇴고 | 대기 |

각 단계는 **지원자의 답 → 보완할 점 → 완성된 답** 순서로 적는다. 완성된 답만 마지막 취합에 쓴다. 이 과정 밖에서 나온 내용(이전 대화의 답, 추론 초안)은 쓰지 않는다.
