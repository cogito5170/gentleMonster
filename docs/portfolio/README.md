## 원칙

- **직관적인 말로 쓴다.** 비유보다 실제 장면(흰 셔츠, 소매, 코트 길이)을 쓴다.
- **멈춘다**가 책 전체를 잇는 동사다. 커버의 질문 "Where did you last stop?"에 각 섹션이 답한다.
- **지원자가 직접 채울 자리는 `____`로 비워 둔다.** 사진으로 확인할 수 없는 사실(신발, 안경, 향, 개인 규칙)은 지어내지 않는다.
- **더 나은 안이 보이면 판단해서 먼저 반영하고, 무엇을 왜 바꿨는지 함께 알린다.** (지원자 지시, v2 작업부터) 사실 확인이 필요한 것(장소 · 연도 · 맡은 일)은 반영하지 않고 묻는다.
- **영어로 쓴 글에는 한국어 해석을 붙인다.** (지원자 요청) 본문은 모두 영어로 지면에 넣고, 원고 · 답변에서는 영어 아래(또는 옆)에 우리말 해석을 함께 둔다.
