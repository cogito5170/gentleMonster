# v2 스토리라인 — v1 이야기를 v2 지면에 다시 놓기

v1 의 흐름([v1_review.md](v1_review.md))을 v2 의 펼침 13개([v2_review.md](v2_review.md))에 맞춰 다시 짠 안. 단계마다 지원자와 정하면서 고친다.

## 뼈대

```
표지  1      나는 세 가지 앞에서 멈춘다. 당신이 마지막으로 멈춘 곳은 어디인가?

(001) STYLE          나는 스타일이 좋은 사람 앞에서 멈춘다
  A  2–3    여는 글                    흰 셔츠 → 길 위에서 멈춘다 → "그래서 내 첫 번째 이야기는 스타일이다"
  B  4–5    Q1 · Q2                    Why is style important? · What makes a good style?
  C  6–7    작업: DAILY LookBook        고르는 눈으로 만든 화면
  D  8–9    다리 ①  큰 글자            I stop for people whose style is their own.

(002) PICTURE        나는 사진 같은 장면 앞에서 멈춘다
  E 10–11   여는 글                    "두 번째로, 내가 멈추는 곳은 장면 앞이다" → "그래서 내 두 번째 이야기는 사진이다"
  F 12–13   Q1                          Why do I take pictures? — 카메라를 들면 관찰한다
  G 14–15   Q2                          What makes a good picture? — 오래 보게 되는 · 이야기가 되는 사진
  H 16–17   사진만                      바다(사람) → 언덕 위 호텔(건물). 시선이 사람에서 장소로
  I 18–19   다리 ②  큰 글자            좋은 사진에는 늘 좋은 장소가 있었다

(003) ARCHITECTURE   나는 좋은 공간 앞에서 멈춘다
  J 20–21   여는 글 + 작업 1            "세 번째로, 내가 멈추는 곳은 좋은 공간 앞이다" → "그래서 내 세 번째 이야기는 공간이다"
  K 22–23   작업 2                      Extension of Chateau
  L 24–25   작업 3 · 4                  지하 탑 콜라주 · 벽돌 · 골조 건물
  M 26–27   모형 + 큰 글자              사람은 공간을 만들고, 공간은 다시 사람을 만든다

끝  28      Where did you last stop?    (지금은 없음 — 새로 만든다)
```

- **세 섹션이 같은 틀이다**: 번호 + 섹션 이름 → 여는 글("○ 번째로, 내가 멈추는 곳은 …" ~ "그래서 내 ○ 번째 이야기는 …") → 질문 두 개 → 보여주기 → 다음으로 넘기는 큰 글자.
- **다리가 두 번, 같은 형식**: D(STYLE → PICTURE)와 I(PICTURE → ARCHITECTURE) 모두 큰 글자 한 줄 + 사진. M 의 큰 글자는 다리가 아니라 책 전체의 한 문장.
- **28쪽**: 표지(1) + 펼침 13개(2–27) 다음 왼쪽 한 쪽이 남는다. 커버 질문으로 돌아오는 마지막 장 자리로 맞고, 28쪽이면 4의 배수라 제본에도 맞다.

## 1단계 결정 (확정)

| 물음 | 결정 |
|---|---|
| 큰 제목 | **섹션 이름이 큰 제목.** STYLE / PICTURE / ARCHITECTURE + 번호 (001)(002)(003). 커버 문구는 작은 부제(A Person with Style / A Moment like A Photograph / A Building That Holds Me). → E 의 MOMENT LIKE A PHOTOGRAPH 는 부제로 줄이고, F 의 PICTURE 큰 제목은 E 로 옮긴다 |
| 웹 디자인 | **STYLE 안 C 그대로.** C 첫 줄로 STYLE 과 잇는다 |
| MY STYLE | **B 에 짧게.** 색 다섯 개 + "그날 갈 장소에 맞춘다" 한 줄 |
| 마지막 장 | **만든다.** 28쪽 |
| 아래 끝 (모든 펼침) | 왼쪽 쪽 아래 두 줄 라벨 = **섹션 표시** — **(002) PICTURE** / (A Moment like A Photograph). 왼쪽 아래 번호 = **펼침 쪽 번호** — 괄호 없이 **08 — 09**. 오른쪽 쪽 아래 한 줄(Experimental Grid Exploration 자리) = **Where Did You Last Stop?** — 커버 질문을 펼침마다 되풀이해 28쪽 마지막 장의 질문으로 이어진다. 괄호 번호 (001)–(003) 은 섹션 번호에만 쓴다 |
| 언어 | **본문 모두 영어** (추가 결정). 원고 문서마다 맨 위 "영어 원고" 절이 지면 기준 |
