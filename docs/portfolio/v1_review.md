# v1 — 기존 포트폴리오 지면 기록

새 버전(v2)과 비교하기 위한 기준. 지원자가 보낸 기존 지면 9장을 그대로 읽은 것이다.

## 반복되는 틀

- **동사 "멈춘다"** 가 커버 질문과 각 섹션 여는 글을 잇는다.
- **영어 질문 제목 + 한국어 답** (Why is … important? / What makes a good …?).
- **각 답의 끝은 공간으로 돌아온다**: "이것은 공간을 만드는 일과 같다", "좋은 공간도 그렇다".
- **사진 캡션** 은 전부 커버 문구의 앞 두 개 "A Person with Style, A Moment like A Photograph,".
- **섹션마다 배경색이 바뀐다**: 올리브(STYLE) → 노랑(PICTURE).

## 흐름에서 끊기는 곳

1. **ARCHITECTURE 섹션이 없다.** 커버가 세 가지를 약속하지만 9장에서 끝난다. 마지막에 커버 질문으로 돌아오지도 않는다.
2. **웹 디자인(4–5)이 이야기 밖에 있다.** "멈춘다"와 이어 주는 문장이 없고, 모브 색이 책의 팔레트와 따로 논다. 위치도 STYLE 과 풀쿼트 사이라 흐름을 끊는다.
3. **STYLE 여는 글에 "그래서 내 첫 번째 이야기는 스타일이다" 가 없다.** PICTURE(8장)에는 있어서 형식이 맞지 않는다.
4. **PICTURE 에 질문 제목이 없다.** STYLE 은 영어 질문 제목이 있는데 8–9장은 본문만 있다(9장 "첫째, 둘째" 는 "What makes a good picture?" 의 답).
5. **9장이 다음으로 넘기지 않는다.** "좋은 사진에는 늘 좋은 장소가 있었다" 같은 ARCHITECTURE 다리가 없고, 아래 절반이 비어 있다.
6. **"앞 페이지의 사진도 그랬다"(8장)** 는 6–7 펼침 사진을 가리킨다. 펼침과 8장 사이에 다른 지면이 들어가면 이 문장이 깨진다.

## 지면 오류

- 3장 색 칩 다섯 개의 HEX 가 모두 `#1D1B19`. Black 칩 색도 올리브로 보인다.
- 5장 필터: 'Material' 제목 중복(두 번째는 Category), 철자 Sprite → Stripe, Chekck → Check, Fliss → Fleece, Hulis → (확인 필요).
- 8–9장 캡션에 텍스트 상자 테두리가 보인다. 8장 캡션 끝에 `]` 가 붙어 있다.
- 2장 리드문과 "Why is style important?" 제목 앞에 공백이 한 칸 들어가 있다(왼쪽 정렬이 어긋남).
