# 커버

## 확정 문구 (지면 기준)

```
SPA

STYLE                    A Person with Style, A Moment like A Photograph,
PICTURE                  A Building That Holds Me — I Stop.
ARCHITECTURE

JEONG HYEOKJU            "Where Did You Last Stop?"
IN GENTLE MONSTER
```

우리말 뜻: 스타일이 좋은 사람, 사진 같은 장면, 멋진 공간과 건축물. 나는 이 세 가지를 만났을 때 멈춘다. 당신이 마지막으로 멈춘 곳은 어디인가?

## 왜 이렇게 정했나

- **SPA는 사람(직업)이 아니라 대상이다.** STYLIST · PHOTOGRAPHER · ARCHITECT 에서 STYLE · PICTURE · ARCHITECTURE 로 바꿨다. "나는 누구인가"가 아니라 "나는 무엇 앞에서 멈추는가"를 말한다.
- **PICTURE**: 사진 한 장이 아니라 '사진 같은 장면'을 뜻한다("It looks like a picture").
- **질문**은 표지 오른쪽 아래에 둔다. 왼쪽 목록이 답이고, 질문이 독자에게 넘어간다.

## 확인한 것

- 스토리라인 설명에 **"SPA (STYLE, PASSION, ARCHITECTURE)"** 로 적힌 곳이 있었다. 두 번째 대상이 '사진 같은 장면'이고 4쪽을 **PICTURE** 로 만들었으므로 **PICTURE** 로 정한다. 지면 · 원고 어디에도 PASSION 이 남지 않게 한다.

## 표지 사진

| | 앞선 사진 (밤 · 빨간불) | 대안 (흐린 날 · 빈 주차장의 차) |
|---|---|---|
| 밝기 / 어두운 영역 | 0.11 / 84% | 0.55 / 1.5% |
| 채도 | 0.31 (빨강·노랑 불빛) | 0 (흑백) |
| 시점 | 차 안, 1인칭 | 차 밖, 3인칭 |
| 시제 | 지금 멈추는 중 | 이미 멈춘 뒤 |

- **표지: 밤 · 빨간불 사진.** 흰 종이 위에서 가장 강하고, 1인칭이라 독자가 그 자리에 앉게 된다.
- **대안 사진은 마지막 장에.** 표지는 '멈춤', 마지막 장은 '멈춘 뒤 남는 자리'. 과거형 질문 "Where did you last stop?"과 시제도 맞는다.
- 수치는 사진 영역을 잘라 잰 값(밝기 0–1, 채도 0–1).

## 검토했던 다른 문구 (기록)

- 표지 한 줄 후보: "You stop in the space. The space stays in you." · "Three ways to make you stop."
- 질문 후보: "What made you stop — a look, a moment, or a place?" (S·P·A 와 1:1로 맞는다)
- "last stop" 은 '종점'으로도 읽힐 수 있다 — 끝·이별의 느낌이 약간 섞인다.
