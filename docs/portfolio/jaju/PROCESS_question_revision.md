- 문항마다 따로 진행한다. 한 문항 안에서는 **단락 단위**로 진행한다.

## 1. 진단 (단락마다 반복)
1. **사례 대조**: 같은 자리의 사례 단락과 순서·연결어·맺음을 비교한다.
   - S2: 내 기준(취향) → "그런 점에서" → 회사 → 하고 싶은 일. 정체성 낱말을 끝에서 새 말로 다시 씀.
   - S1: 내 경험 → 관점 → 회사 사실 1~2개 → 내 역할. 맺음은 "입사 후 … 나아가 …" 두 문장, 소제목으로 돌아옴.
   - 공통 원리: ① 단락 첫 문장이 앞 단락을 받음 ② 주장 → 근거 → 의미 → 역할 ③ 다짐은 끝에 한 번 ④ 소제목이 끝에서 돌아옴 ⑤ 능력은 첫째·둘째 ⑥ 첫머리 정체성 낱말을 뒤에서 근거로 다시 씀.
2. **공고 대조**: 업무·자격·우대 항목을 하나씩 표로 대 본다 (충족 / 부분 / 공백).
3. **사실 대조**: 문장마다 출처를 단다 (사용자 사실 기록, 포트폴리오 문구, 1차 기사). 출처 범위를 넘는 일반화 금지 (예: 매장 하나의 발표 → 브랜드 전체의 가치로 넓히지 않음, 컬렉션 하나 → 상품 전체로 넓히지 않음).
4. **문항 간 대조**: 같은 일화·같은 문장이 다른 문항과 겹치는지, 다른 문항의 정의와 충돌하는지 본다 (예: 라운딩 = 매장마다 '같은' 기준).
5. **낱말 점검**: 핵심어 반복 횟수를 센다 (같은 낱말 한 단락 3회 이상이면 줄임), 같은 문장 끝("됐습니다" 연속), 같은 경험 2회 이상.

## 2. 사용자가 거부한 표현 (다시 쓰지 않음)
- 추상어·비유로 끝나는 맺음 ("시선으로 매대를 채우다", "가능성을 찾아 해결하는").
- 공고 문구를 옮겨 적은 문장 ("매장 오픈과 리뉴얼까지 맡아").
- 근거 없는 능력 선언 ("공간감"을 설명 없이 내세움) → 같은 단락이나 뒤에서 근거를 붙이거나 쉬운 말로 풀어 줌.
- 확인되지 않은 감정어 ("공감합니다", "꿈꾸게", "아쉬웠습니다", "눈이 갔습니다").
- 과장 ("가장 큰 어려움", "도맡다", "모두 해 본 일").
- 막연한 다짐 ("최선을 다하겠습니다") → 공고 요건에 답하는 구체 다짐 ("JAJU와 오래 함께하겠습니다").
- 문법: "~로서"는 사람·자격 뒤, "이는 … 담았습니다"(주어 불일치) 등.

## 3. 해결 (사용자 지시에 따라)
- **분석만** / **방향만** / **수정** 을 구분해 지시대로만 한다. "수정하지 않는다"면 글을 바꾸지 않는다.
- 안을 낼 때는 유형별 2~3안 + 비교표 + 추천 1개. 바꾼 곳은 이전/수정 표로 보여 준다.
- 사용자가 직접 고친 문장은 그대로 반영하고, 문제는 검토로만 알린다.
- 사용자만 답할 수 있는 것(직접 겪은 경험, 감정, 근무 조건)은 문장을 지어내지 않고 질문으로 남긴다.
