### 11쪽 본문 — 여는 글

> **두 번째로, 내가 멈추는 곳은 멋진 장면 앞이다.** 빛, 색, 사람, 장소가 한순간에 맞아떨어질 때가 있다. 그때 나는 카메라를 꺼낸다.
>
> **앞의 거리 사진**도 그랬다. 헤드폰을 쓴 사람, 체크 셔츠와 슬리퍼, 그리고 그 뒤의 화분과 **칠판. 사람과 장소가** 함께 맞아떨어진 순간이었다.
>
> 그래서 내 두 번째 이야기는 사진이다.

바뀐 곳(굵게):
1. 첫 문장을 되살렸다 — STYLE 여는 글 "첫 번째로, 내가 멈추는 곳은 길 위다" 와 짝이고, 커버 질문 *Where did you last stop?* 에 대한 두 번째 답이다.
2. "앞 페이지의 사진" → "앞의 거리 사진" — 8–9쪽 풀쿼트 펼침의 거리 사진을 가리킨다. 사이에 10쪽 제목 장이 있고 바로 위에 기차 사진이 있어도 잘못 읽히지 않는다.
3. "화분과 사람, 장소가" → "화분과 칠판. 사람과 장소가" — v1 원문으로 되돌렸다.

※ 8–9쪽 거리 사진을 지원자가 직접 찍었다는 전제다. 아니라면 둘째 단락을 뺀다.

## 지면 반영

둘 중 하나로 한다. 둘 다 10–11쪽 펼침 안의 것만 고친다 — 다른 펼침 · 마스터 페이지는 건드리지 않는다. 글 상자를 id 가 아니라 **글 내용으로** 찾으므로 A–D 를 먼저 고친 문서에도, 고치지 않은 문서에도 그대로 쓸 수 있고, 두 번 돌려도 결과가 같다.

### InDesign 에서 바로 — [scripts/v2_E_picture_10-11.jsx](scripts/v2_E_picture_10-11.jsx)

1. 책 .indd 를 연다.
2. 창 → 유틸리티 → 스크립트 → 사용자 폴더에 넣고 두 번 클릭 (또는 파일 → 스크립트 → 스크립트 찾아보기).
3. 끝나면 바꾼 것 · 못 찾은 것 · 넘친 글 상자 · 겹침 후보 · 남은 템플릿 글을 알려 준다.
4. 마음에 안 들면 편집 → 실행 취소 **한 번**으로 전부 되돌린다.

큰 제목의 크기 · 자리는 문서 2쪽의 STYLE 제목을 읽어서 맞춘다(2쪽은 읽기만 한다). 2쪽 STYLE 을 못 찾으면 글만 바꾸고 알려 준다.

### IDML 로 — [scripts/idml_E_picture_10-11.py](scripts/idml_E_picture_10-11.py)

```
python3 docs/portfolio/scripts/idml_E_picture_10-11.py 원본.idml 결과.idml
```

- 원본 IDML 에 10–11쪽이 한 펼침으로 들어 있으면 된다(책 전체든, 10–11쪽만 내보낸 것이든).
- 결과 IDML 을 InDesign 에서 열고 .indd 로 저장한다.
- 큰 제목의 크기 · 자리는 A 반영본(`포트폴리오 2-3 수정.idml`)의 2쪽 STYLE 에서 잰 값(Helvetica Bold 136.02pt, 왼쪽 쪽 기준 x 56.7–961.7 · y 100.3–338.3pt)을 쓴다.
- 검사: `python3 docs/portfolio/scripts/test_idml_E_picture_10-11.py` — 10–11쪽과 8–9쪽이 든 IDML 을 코드로 지어 걸어 본다. E 가 원고대로 바뀌는지, **8–9쪽 펼침과 그 스토리가 한 바이트도 바뀌지 않는지**, 두 번 돌려도 같은지를 본다.

## 지원자가 정하거나 볼 것

1. **캡션 단어** — *Puddle* 은 제안이다. 이 사진 앞에서 실제로 멈춘 이유로 고친다. 스크립트 위쪽 `CAPTION` 한 줄만 바꾸면 된다(필요 없으면 `""`).
2. **기차 사진 테두리가 그림 파일 안에 있으면** 스크립트로 못 뺀다. 스크립트가 "InDesign 테두리가 없음" 이라고 알리면 그림 원본에서 지운다.
3. **큰 제목과 (002) 가 겹치지 않는지** — 2쪽 STYLE 자리로 옮긴 PICTURE 가 10쪽의 (002) 와 부딪히면 스크립트가 "겹침 후보" 로 알린다. 그때는 (002) 를 옮긴다(2–3쪽은 (001) 이 3쪽에 있다).
4. **본문 글꼴** — A 3쪽 본문은 AppleGothic 13pt · 행간 20.8pt 다. E 본문이 다르면 맞춘다(IDML 스크립트가 지금 글꼴 · 크기를 알려 준다).
5. 8–9쪽 거리 사진이 직접 찍은 것인지 (아니면 여는 글 둘째 단락을 뺀다).

## 이 펼침 밖이라 여기서 하지 않은 것

- F-13 의 큰 제목 **PICUTRE**(오타) — PICTURE 큰 제목은 E-10 으로 옮겼으므로 F 에서는 지운다. F 작업에서 한다.
- 12 · 14쪽의 (003) — ARCHITECTURE 번호라 PICTURE 지면에서 뺀다. F · G 작업에서 한다.
- 2쪽 · 3쪽(A)은 읽기만 한다(JSX 가 STYLE 제목의 크기 · 자리를 읽는다).
