# 자기소개 — 건축학과 재학생으로서의 나

조건: 문항 문구 · 글자 수 `[확인 필요]` · 지원 분야: Gentle Monster 공간 디자인

## 진행 방식

[cover_letter.md](cover_letter.md)와 같다. 단계마다 지원자가 답을 내고, 보완해 완성된 답을 확정한 뒤 넘어간다. **틀 먼저, 세부는 나중.** 앞서 커밋한 내용은 참고 자료로 쓰고, 고칠 곳은 지원자가 정정한다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 문항과 분량 확인, 지원동기 글과 역할 나누기 | 진행 중 |
| 2 | 나를 한 줄로 — 건축학과에서 무엇을 가져왔나 | 대기 |
| 3 | 근거가 되는 설계 경험 1–2개 | 대기 |
| 4 | 건축 전공이 공간 디자인에서 강점인 이유 (차별점) | 대기 |
| 5 | 왜 건축이 아니라 공간 디자인인가 | 대기 |
| 6 | 젠틀몬스터에서 건축의 시선으로 할 수 있는 것 | 대기 |
| 7 | 구조와 분량 | 대기 |
| 8 | 퇴고 (지원동기 글과 겹침 확인) | 대기 |

## 출발점 — 지원자가 정한 강점

> 조금 특이하고 강점이 될 수 있는 점은 '건축학과' 재학생이라는 것이다.

## 뼈대 가설 (지원자가 정정한다)

| 흐름 | 내용 | 근거 |
|---|---|---|
| 정체성 | 건축학과에서 공간을 평면이 아니라 **단면과 시퀀스**로 보는 법을 배웠다 | 지원동기 ①의 "압축 → 팽창" 관찰이 단면의 언어다 |
| 근거 | 설계 스튜디오 프로젝트 `[무엇]`에서 `[무엇을 어떻게]` 했다 | 지원자 답 필요 |
| 차별점 | 주어진 실내를 꾸미는 것이 아니라, 진입부 · 수직 동선 · 외부와 내부의 경계까지 건물 단위로 생각한다 | 젠틀몬스터 플래그십은 건물 전체가 매장인 경우가 많다 (지원자가 본 홍대점) |
| 선택 | 건축이 아니라 공간 디자인을 택한 이유 `[무엇]` | 지원자 답 필요 |
| 기여 | 이용자가 멈추고, 이끌리고, 그 경험을 기억하는 공간을 건물 단위로 설계한다 | cover_letter.md 2단계 축 |

## 1단계 — 문항과 분량, 역할 나누기

지원자에게 물을 것

1. 자기소개 문항의 정확한 문구와 글자 수
2. 학년 (건축학과 몇 학년, 5년제인지)
3. 지원동기 글과의 역할 나누기: 갤러리 설계 · 리움 이야기는 지원동기 ①에 이미 쓰였다. 자기소개에서는 **다른 프로젝트**를 근거로 쓰는 것이 좋다. 갤러리 말고 어떤 설계 프로젝트를 했나?
4. 건축학과 학생이 건축사사무소가 아니라 젠틀몬스터 공간 디자인에 지원한 이유 (면접에서도 물을 가능성이 높다)
