## 문맥 흐름 분석 (S1~S5, 허브, 2026-10-16)

| ID | 1번 문항 흐름 | 단락을 잇는 장치 | 끝맺음 |
|---|---|---|---|
| S1 | 공간 경험(고유명사) → 관점 문장 → 회사 비전 키워드 → 회사 사례 → 직무로 실현 → 감각 근거 → "또한" 준비 → 결과 → 입사 후 | "이러한 관점에서", "저는 이러한 신세계의 혁신을 실현하는 바이어로서", "또한 저는" | 소제목 '랜드마크'로 회귀 |
| S2 | 정체성 → 받는 질문 → 정체성 재정의 → 좋아하는 것(구체) → 인턴 체감 → 휴학 목표 → 브랜드 정체성 묘사 → 하고 싶은 일 → 전공의 도움 | 키워드 되받기('정체성', '목적') | 전공이 회사·나에게 주는 도움 |

| S4 | 관심 계기 → 회사의 위기 대응 → 성장 기대 → 지원 / 업무 본질 정의 → 노력 | "따라서", "우선", "또한" | 실무에서 배운 점 |
| S5 | 업계 위기 → 회사의 대응·성장 → 기여 목표 / 노력 첫째·둘째·셋째 | "이러한", "첫째·둘째·셋째", "이를 바탕으로" | 목표 재진술 |

공통 원리
1. 단락 첫 문장이 앞 단락을 받는다('이러한', '또한', '이를 바탕으로').
2. 단락 안은 주장 → 근거 → 의미 → 내 역할 순서.
3. 다짐(입사 후)은 글 끝에 한 번 모은다.
4. 소제목·첫 키워드가 끝에서 돌아온다(수미상관).
5. 지원 이유 다음에 준비·역량, 역량은 '첫째·둘째'로 나눈다.
6. 첫머리에 세운 정체성 키워드가 뒤에서 근거로 다시 쓰인다(S2 '소비자학').
