# B3 발언·키워드 추출 — BLUE ELEPHANT (초안, 2026-10-13)

모두 검색 요약에 실린 인용이며 기사 원문은 확인하지 못했다(🔎). 여러 매체에 같은 문장으로 실린 발언은 "다수 매체"로 표시. 대표 개인 인터뷰는 찾지 못해, '관계자'(회사 공식 입장) 발언이 중심이다.
