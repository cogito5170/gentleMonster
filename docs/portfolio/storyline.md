# 전체 스토리라인

커버가 묻고, 세 섹션이 차례로 답하고, 마지막에 다시 묻는다.

```
커버            나는 세 가지 앞에서 멈춘다. 당신이 마지막으로 멈춘 곳은 어디인가?
01 STYLE        → 나는 스타일이 좋은 사람 앞에서 멈춘다        (스타일)
02 PICTURE      → 나는 사진 같은 장면 앞에서 멈춘다            (사진)
03 ARCHITECTURE → 나는 좋은 공간 앞에서 멈춘다                (공간)
마지막 장       → "Where did you last stop?" 을 다시 묻는다
```

## 섹션마다 같은 틀

| | 여는 글 | 보여주기 | 마무리 (다음 섹션으로) |
|---|---|---|---|
| **01 STYLE** | 내가 가장 자주 멈추는 곳은 길 위다 | 나의 스타일 (룩 분석 · SECTOR A) | 스타일이 좋은 사람이 좋은 장소에 서 있으면, 그 장면은 한 장의 사진이 된다 |
| **02 PICTURE** | 나는 사진 같은 장면 앞에서 멈춘다 | 내가 찍은 사진 + 찍은 이유 | 좋은 사진에는 늘 좋은 장소가 있었다 |
| **03 ARCHITECTURE** | 나는 좋은 공간 앞에서 멈춘다 | 공간 작업 (시놉시스 · 무드보드 · 도면) | 커버의 질문으로 돌아간다 |

각 섹션의 여는 글은 "그래서 내 첫 번째(두 번째, 세 번째) 이야기는 ○○이다"로 끝난다. 같은 형식이 반복되어 섹션이 바뀌는 지점이 분명해진다.

## 01 STYLE 안의 흐름

```
① 여는 글 (A안)        나는 스타일이 좋은 사람 앞에서 멈춘다
② 전환                 그 눈으로 나를 본다
③ 나의 스타일 (사진)    머리 · 안경 · 옷 · 신발 · 액세서리 · 색 · 향  → SECTOR A
④ Q1–Q3               스타일에 대한 생각
⑤ 마무리 → 02 PICTURE  스타일이 좋은 사람이 좋은 장소에 서면, 사진이 된다
```
