## 끊기는 이유
1. 표지가 약속한 세 장(ARCHITECTURE · STYLISH · DETAIL)이 본문에 다시 나오지 않는다 — 장 표지 · 목차가 없다.
2. 같은 종류가 흩어져 있다 — 전시 2 · 6, 웹 5 · 8, ARCHITECTURE 아이덴티티 4 · 7 · 10 · 14(14 는 Thank you 뒤).
3. 작업 쪽에 글이 없다 — 2–11 · 14 는 제목 · 무엇을 했는지 · 도구가 없고, P/ 쪽 번호도 Resume · Thank you 에만 있다.
4. 쪽마다 바탕 톤이 크게 바뀐다(노랑 → 검정 → 크림 → 회색 → 청록) — 이어 주는 공통 요소가 없다.
5. 같은 사진을 다섯 매체(전광판 · 실외 · 실내 · 웹 · SNS)에 넣은 흐름이 순서와 글에서 드러나지 않는다.

## 대안
- **A (권함) 표지 버튼 = 장**: Cover → Index → Resume → 01 ARCHITECTURE(로고 · 택 둘 · 아크릴) → 02 STYLE(캠페인 · 웹 히어로 · Style & Display) → 03 DETAIL(전광판 → 실외 → 실내 → SNS, 큰 틀에서 작은 틀로) → Thank you. 새 쪽 4(Index · 장 표지 3), 18쪽. 그림: `flow_option_A.png`
- **B 한 장면, 다섯 틀 (최소 수정)**: 장 표지 없이 순서만 — 아이덴티티 → 캠페인 → 전광판 → 실외 → 실내 → 웹 → SNS, 큰 틀(도시)에서 작은 틀(손 안)로. 쪽마다 캡션만 더함.
- **C 스페이스 2.0 (터널 · 구조 · 장면 + KEEP, D48)**: TUNNEL(표지 · 전광판 · 실외) → STRUCTURE(아이덴티티 · 아크릴 · 실내) → SCENE(캠페인 · 웹 · SNS) → KEEP(Resume · Thank you). 표지 버튼을 TUNNEL · STRUCTURE · SCENE 으로 바꿔야 함.

## 어느 안이든 함께 할 것
- 모든 작업 쪽에 Resume · Thank you 와 같은 왼쪽 세로 'P/ nn | 장 이름' + 작은 캡션(제목 · 무엇 · 도구 · AI 사용 여부) 한 덩이.
- 장 표지는 Resume. · Thank you. 와 같은 꼴(밝은 회색 · 옅은 큰 글자)로 — 책 전체가 한 체계로 읽힌다.
- 표지 오타: 'BLUEELLEPHANT' → BLUE ELEPHANT, 버튼 'ARCHITECTUR' → ARCHITECTURE.
