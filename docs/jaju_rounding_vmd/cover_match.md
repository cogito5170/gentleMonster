## 사례에서 가져온 것 → 표지에
| 사례 | 표지 |
|---|---|
| 글은 왼쪽 빨간 면 안에만, 인물 · 흰 벽 · 바닥은 비움 | 왼쪽 파란 벽(폭 104.5mm) 안에만 |
| 위: EDITED BY / 이름 / AND / 이름 (작은 줄 · 큰 줄 번갈아) | PART 2 / **/02 MATCH.** / OF / **FROM THE INSIDE** |
| 흰색 좁은 굵은 제목 두 줄, 검정 '+' 로 잇기 | **CLOTHES + PLACE** (흰색, '+' 검정) — 파트 2 의 끝 문장 '옷은 놓인 장소와 맞을 때 완성된다.' |
| 검정 작은 대문자 부제 네 줄, 바닥 사선 위에서 끝 | MATCHING MY OWN CLOTHES, / TO FIND THE HARMONY / THAT MAKES / PEOPLE STOP. |
| — | 한국어(2-2 확정 표지 글): 사람을 멈추게 한 조화를, / 내 옷으로 맞춰 본다. |

- 크기: 위 작은 줄 7.6pt(자간 90) · 큰 줄 22pt · 제목 54pt / 행간 50pt · 부제 7.6pt / 13.2pt(자간 100) · 한국어 9.4pt. 왼쪽 여백 14mm.
- 좁은 굵은 글꼴이 이 환경에 없어 Instrument Sans Bold 장평 74%. InDesign 에서 가진 좁은 고딕으로 바꿔도 된다. 한국어는 210 타임라인.
- 사용자 표지 이미지 파일은 이 세션에 없다(채팅 첨부는 저장되지 않음). 미리 보기의 색 면 · 인물 점선은 화면 캡처에서 잰 자리 표시일 뿐이다.
  InDesign 파일에서 표지 이미지를 맨 아래에 놓거나, 글 상자를 표지 문서로 복사해 쓴다. 이미지 파일을 올려 주면 합쳐서 다시 낸다.
