## 지면 계획 (A4 가로 · 약 14쪽 · B안의 검정 바탕)

장마다 Galatasaray 의 순서로 간다: **보이기(여는 면) → 증명(여러 장) → 디테일**.

| 쪽 | 장 | 면 | 무엇을 | 재료 |
|---|---|---|---|---|
| 표지 | — | 사진 띠 + 제목 · 메시지 | (완료) | 표지 이미지 |
| 1 | Prologue | 좁은 단의 글 + 녹아드는 이미지 | (완료) | 표지 이미지 |
| 2 | **장 1 · 사진 — 관찰하다** | 여는 면 | 장 제목 + 한 문장, 가장 강한 사진 한 장 크게 | 사진 1 |
| 3 | | 격자 | 같은 크기 6–9장 — 내가 걸음을 멈춘 일상 | 사진 6–9 |
| 4 | | 디테일 | 사진 두세 장 위에 초점 원 · 점선 틀 — 무엇에 멈췄나(빛 · 색 한 점 · 반복) | 사진 2–3 |
| 5 | **장 2 · 건축 — 담다** | 여는 면 | 장 제목 + 한 문장, 모형 사진 크게 | 모형 사진 1 |
| 6 | | 도면 | 평면 · 단면, 비워 둔 자리(마당)에 점선 틀, 동선 화살표 | 도면 2–3 |
| 7 | | 디테일 | 같은 공간을 진열의 눈으로: 눈높이 · 동선 · 시선이 닿는 곳 | 도면 · 모형 사진 |
| 8 | **장 3 · 패션 — 채우다** | 여는 면 | 장 제목 + 한 문장, 착장 전신 크게 | 착장 1 |
| 9 | | 2×2 | 같은 아이템 · 다른 조합 — "자주 쓸수록" | 착장 4 |
| 10 | | 분해 | 착장 한 벌을 아이템 · 색 비율로 | 착장 1 + 아이템 컷(있으면) |
| 11 | **제안** | 하나의 진열 | 세 장을 매장 진열 하나에: 관찰한 것(사진) · 놓일 자리(도면) · 채운 조합(착장). '제안'이라고 적는다 | 위 재료 + 코드 도면 |
| 12 | 닫는 면 | 다시 모으기 | 앞의 사진 · 도면 · 착장을 다시, 한 문장으로 닫기 + 연락처 | 앞의 것 |

쪽 수는 재료를 본 뒤 2–3쪽 늘거나 준다.

## 프로세스

각 단계는 **사용자 확인**으로 끝난다. 확인 전에는 다음 단계로 넘어가지 않는다.

### 1. 재료 받기 — 사용자

보내 주실 것 (원본 파일 그대로, 줄이지 않고):

| 카테고리 | 장수 | 함께 적어 주실 것 |
|---|---|---|
| 사진 | 15–25장 | 찍은 곳 · 때 (짧게) |
| 건축 | 프로젝트 1–2개: 모형 사진 · 평면 · 단면 · 대표 렌더 | 프로젝트 이름 · 학년 · 주제 한 줄 · 대지 |
| 패션 | 착장 8–12장 (전신 · 뒷모습 포함, 같은 옷을 다르게 입은 것이 있으면 꼭) | 아이템 이름 · 색 (아는 만큼) |

받은 것에 없는 사실(장소 · 치수 · 브랜드)은 지어내지 않고 `____` 로 둔다.

### 2. 재료 정리 — Claude

- 받은 순서대로 번호(`PH-01`, `AR-01`, `FA-01` …)를 붙이고, 해상도 · 방향 · 주된 색 · 빨간 한 점 유무 · 점선 틀을 얹을 자리를 표로 적는다.
- **밀착 인화지(contact sheet) PDF** 한 벌: 카테고리별 썸네일 + 번호 + 해상도 경고(인쇄 300 ppi / 화면용 150 ppi 기준).
- 산출물: `docs/jaju_rounding_vmd/assets.md` · `contact_sheet.pdf`.

### 3. 고르기 · 다리 놓기 — Claude 제안 → 사용자 확인

- 위 지면 계획의 칸마다 후보 1–2장을 제안한다.
- 장과 장을 잇는 **사물 하나**를 고른다 (예: 표지의 유리 → 사진 속 창 / 사진 속 공간 → 건축의 마당 / 마당의 빈 자리 → 착장의 빈 자리).
- 산출물: 칸마다 고른 번호가 적힌 `selection.md` + 고른 것만 모은 PDF.

### 4. 글 — Claude 초안 → 사용자 확인

- 장마다 영문 제목 한 낱말 + 국문 한 문장 + 영문 한 줄. JAJU 의 말(관찰 · 담다 · 채우다 · 자주)로.
- 캡션은 낱말 하나(`Light` · `Courtyard` · `Combine` 같은).
- 산출물: `text.md` (쪽마다 글 · 글자 수).

### 5. 장별 시안 — Claude → 사용자 확인 (PDF 로만)

한 장씩 낸다. 사진 장 → 확인 → 건축 장 → 확인 → 패션 장 → 확인 → 제안 · 닫는 면.

- 지면 문법: 표지 B안과 같은 검정 바탕 · Pretendard · 회색 단계 · 작은 표기. 색은 사진 안에만.
- **점선 틀 · 초점 원**은 코드로 그린 벡터로 얹는다(JAJU 화면의 장치, 9쪽 시안의 Focal point 와 같은 방식). 되풀이할지는 사진 장 시안에서 정한다.
- 이미지를 새로 만들지 않는다. 자르기 · 배치만. 도면 · 다이어그램은 코드 렌더.

### 6. 전체 묶기 — Claude → 사용자 확인

- 표지부터 닫는 면까지 한 PDF. 쪽 넘김의 리듬(큰 그림 → 여러 장 → 디테일)과 장 사이 다리를 다시 본다.
- 확인할 것: 사실(지어낸 것 없음) · '제안' 표기 · JAJU 자산 미사용 · 글 분량.

### 7. InDesign 파일 — Claude

- 최종 지면을 IDML + JSX + `Links/` 한 폴더로(표지 B안과 같은 방식). 사용자가 InDesign 에서 마지막 손질.

### 8. 제출본 — Claude → 사용자

- 이미지를 화면용(긴 변 약 2500 px, JPEG 품질 80 안팎)으로 줄여 넣은 **제출용 PDF**를 따로 뽑는다 — 목표 8MB 이하(10MB 한도에 여유). 이 환경에 PDF 압축 도구(Ghostscript)가 없어서, 이미지를 넣기 전에 줄이는 방식으로 맞춘다.
- 파일 이름: `JAJU라운딩VMD_성명_포트폴리오.pdf`, 압축 파일 `JAJU라운딩VMD_성명.zip`.
- 인쇄용 원본(고해상도)은 따로 둔다.

### 9. 최종 점검 — 사용자

- 메일 제목 `JAJU 라운딩 VMD / 성명` · 첨부(이력서 · 자기소개서 · 포트폴리오) · 크기 10MB 이내.
- 공고 마감 여부(문의 메일 답장)를 확인한 뒤 보낸다.
