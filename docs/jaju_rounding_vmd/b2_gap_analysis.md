## 자세히

### 1. 크기의 리듬이 없다 — 모든 쪽이 같은 무게
- 14쪽 중 13쪽이 '왼쪽 글 단 + 오른쪽 사진 덩어리'다. 넘겨도 속도가 바뀌지 않는다.
- ETÉREO 는 가운데(해녀)에 유일한 양면 전면을 두고, NEA 는 장마다 도해 면으로 멈춘다. B2 는 파트가 바뀌는 쪽(02 · 05 · 08)도 같은 틀이라 **파트가 바뀌었다는 느낌이 약하다**.
- 피드백("무드가 먼저", "디자인과 내용이 같은 무게라 둘 다 흐려진다")과 같은 지적이다.

### 2. 글자 위계가 평평하다
- 제목(`Where people stop`, `A room, set like a display`)이 9–10pt — 본문과 거의 같은 크기라 눈이 걸리지 않는다.
- 영문은 6–7pt 회색이라 읽히지 않고 장식으로만 남는다(피드백 2번). 둘 중 하나: 읽히게 키우거나 뺀다.
- 한 글꼴(산세리프)만 쓴다. 사례는 모두 두 글꼴(세리프 제목 + 산세리프/모노 보조)로 위계를 만든다.

### 3. 검정 바탕이 JAJU 와 사진을 거스른다
- 기업 분석: JAJU 는 오렌지 · 틸블루 · 올리브, '포근하고 재미있는' 톤으로 가고, **차분한 무채색 · 베이직을 버리려** 한다.
- 사진 대부분이 따뜻한 빛(노을 · 실내 조명 · 노점 네온)이다. 차가운 검정 위에서 색이 뜬다(피드백: "사진 색감이 블랙/화이트에 안 맞는 경우").
- B2 톤을 지키면서 할 수 있는 것: **따뜻한 검정**(#14110E 같은 갈색 기 도는 검정), 회색 글자를 따뜻한 회색으로, 강조색을 순빨강 대신 JAJU 오렌지 쪽으로.

### 4. 실 한 가닥이 끊긴다
- 표지의 '유리 너머 · 안에서 밖' 시선이 파트 안에서 다시 나오지 않는다. 08쪽 FA-02(유리 안에서 밖을 봄)가 유일한 메아리.
- 빨강: 표지 스카프 → 장 1 빨간 원 → 장 2 빨간 후드 · 조각 → 제안의 빨간 칸. 같은 색이지만 **표시 도구(원)와 사진 속 사물이 섞여** 의미가 흐려진다. 하나로 정해야 한다 — 사진 속 사물에만 쓰거나, 표시에만 쓰거나.
- 표지 사진이 표지 · 01 · 12쪽에 세 번 나온다. ETÉREO 의 '다시 쓰기'는 끝에서 한 번이다 — 01쪽의 재사용이 이르다.

### 5. 캡션이 설명조이고 체계가 없다
- VERLAG 는 모든 쪽에 같은 모양의 메타 블록을 둔다. B2 는 쪽마다 캡션 방식이 다르다.
- 피드백 4번: Stop · Pause 같은 설명 대신 장소 · 시간 · 촬영값 같은 '레터링 같은 데이터'. 사진에 촬영 정보가 없으니(EXIF 없음) **장소 · 때 · 사진에서 잰 색**으로 하나의 메타 체계를 만들 수 있다(경이 안에서 시험한 방식).

### 6. VMD 로서의 증거가 얇다
- 라운딩 VMD 공고가 보는 것: 매장 순회 · 진열 · 환경 개선 · 오픈/리뉴얼 · **패션 스타일링**.
- B2 에서 그 일을 '보여 주는' 쪽은 10(착장 분해) · 11(제안) 둘이다. 나머지는 관찰 · 건축 감각이다.
- 제안(11)은 빨간 칸 · 굵은 선의 도식이라 실제 진열처럼 읽히지 않는다(피드백 12번 '플라스틱').
- 사례가 증명하는 방식: Galatasaray 는 **전부를 표로**, 마지막에 **짓는 법**. 지원자 재료로 가능한 것:
  - **매장 관찰 기록**: 이미 가진 사진 중 가게 앞 장면(PH-04 노점 · PH-06 푸드 트럭 · FA-04 생활용품 진열창)을 '다른 매장의 진열을 읽는' 쪽으로 — 라운딩 VMD 의 눈. (지어내지 않음: 사진 위에 눈높이 · 조닝 · 시선을 표시만)
  - **제안을 한 매장의 한 칸으로 구체화**: JAJU 매장 언어(칸 · 평상 · 마당)로 정면도 + 평면, 가는 선, 실제 사진의 결. 치수는 '재서 정한다'로 두고, 일반적으로 쓰는 눈높이 범위만 표시.
  - 가능하면 **종이 목업 사진 한 장**(1:10) — 사용자가 직접 만들어 찍으면 가장 강한 증거가 된다.

### 7. 끝이 약하다
- 12쪽: 사진 6장 콜라주 + 선언 — 앞쪽 쪽들과 같은 밀도라 '끝'으로 읽히지 않는다(피드백 13번 '올드').
- 뒤표지: 검정 위 작은 `Outside` — 표지의 장치(이름 거꾸로 → 바로 읽힘)가 여기서 회수되지 않는다.
- 사례: ETÉREO 는 마지막에 그리드를 한 번 깨고, Skate zine 은 질문 → 지금 → 선언, Galatasaray 는 짓는 법.

### 8. 기술 · 제출
- 9.1MB — 10MB 한도에 가깝다. 쪽을 더하면 넘는다.
- 사진이 긴 변 1500px 안팎 — 화면용은 되지만 인쇄는 흐리다.
- PDF 의 한글이 이 환경의 대체 글꼴(문천역정흑)이다. 최종본은 Pretendard(InDesign)로.
