작성일: 2026-10-21. 근거: 사용자가 전한 타인의 피드백(잡지사 경력). **B2(`layout/plan_b2.pdf`)는 그대로 유지**하고 따로 만든 안이다.
PDF: `layout/plan_e.pdf` (14쪽 · 약 8.1MB) · 만드는 법: `python3 tools/jaju_layout/plan_e.py`

## 전체 피드백 → 이 안의 답

| 피드백 | 답 |
|---|---|
| 잡지는 내용보다 무드가 먼저. 레이아웃은 '사진 위 · 글 아래' 또는 '사진 옆 · 글 반대편' 둘 중 하나 | 쪽마다 둘 중 하나만 쓴다. 각 파트는 **사진 전면의 무드 쪽**으로 연다 (2 · 8쪽, 5쪽은 글자가 사진을 담는 쪽) |
| 디자인과 내용이 같은 무게라 둘 다 흐려진다 | 무드 쪽은 글을 한 줄로, 내용 쪽은 표시 · 장식을 줄였다 |
| 흑백의 단조로움 · 사진 색감이 흑백에 안 맞는다 | 검정 대신 **따뜻한 종이색**(#EDE6DA) · 짙은 갈색 먹(#2A231C) · 강조 **테라코타**(#B0532C, JAJU 의 오렌지 쪽) |
| 글자를 조금 굵게, 따스하게 | 제목 **Young Serif**(굵고 둥근 세리프) · 영문 본문 **Lora** · 데이터 글자 **IBM Plex Mono**. 한글 본문 굵기를 올림 |
| Part 를 나누어 | PART 1 OBSERVE · PART 2 CONTAIN · PART 3 FILL, 바닥 줄에 파트 이름 |

## 쪽별

| 쪽 | 피드백 | 바꾼 것 |
|---|---|---|
| 표지 | 폰트가 와닿지 않고 메시지가 직관적이지 않다 | 사진 전면, 굵은 세리프 `From the Inside` 크게, 한글 메시지 굵게 바로 아래 |
| 01 Prologue | 제목과 한글 크기가 같다 · 영문이 작아 장식처럼 보인다 · 시선 분산 | 사진 왼쪽 \| 글 오른쪽. 제목 32pt → 한 줄 인용 16pt 굵게 → 본문 10pt → 마지막 다짐 굵게 → 영문은 읽히는 크기(8.6pt 이탤릭) |
| 02 Observe | 많이 써 있고 임팩트 부족 | 사진 전면 + `Observe` 118pt, 한 줄만 |
| 03 Where people stop | 가장 좋음. 단, 설명이 아니라 레터링 같은 데이터로 | 배치 유지. Stop · Pause … 대신 **N°번호 · 때 · 사진에서 잰 색(HEX 와 색칩)**, 왼쪽 아래 레터링 `17 FRAMES / 09 SHOWN … THE POINT WHERE MY EYE STOPPED.` |
| 04 What made me stop | 빨간 원보다 디자이너블한 포인트 | **카메라 초점 칸**(네 모서리 · 가는 지시선 · 모노 글자)으로 교체 |
| 05 Contain | '담다'를 아래 적기보다 진짜 담는 느낌 | **`Contain` 글자 안에 격자 골조 모형 사진을 담았다.** 한글은 네모 틀 안의 `담` — ㅁ 이 마당이자 진열대 한 칸 |
| 06 City → room | 굉장히 마음에 듦 | 배치 그대로, 톤만 |
| 07 A room | — | 배치 그대로, 표시를 초점 칸으로 |
| 08 Fill | 단어 나열보다 무드가 먼저 | 유리창 너머 바다를 보는 사진 전면, 하늘 자리에 `Fill` 한 단어와 한 줄 |
| 09 Four places | 무난함 | 사진 한쪽(밤 강변 전면) \| 글 · 세 착장 · 팔레트(HEX) 다른 쪽 |
| 10 Breakdown | "매장 안의 손님은 마네킹의 등을 먼저 본다"가 중요한데 회색이라 안 보인다 | 그 문장을 **20pt 굵게** 큰 인용으로 |
| 11 Proposal | 플라스틱하고 마감이 딱딱하다 | 빨간 칠 · 굵은 선 대신 가는 선 칸 + 칸마다 실제 사진의 결(무드 예시) + 테라코타 점 하나 |
| 12 Often | 너무 올드 · 글 줄이거나 사진 위 + 번호 + 아래 산문 | **사진 다섯 장 위 · 번호(N°01–05) · 아래 산문** |
| 뒤표지 | — | 종이 위 작은 사진 · Outside |

## 한계

- 이 환경의 한글 글꼴이 문천역정흑 하나뿐이다. 한글이 따뜻한 느낌을 덜 주는 이유다. 최종본은 따뜻한 한글 세리프(예: 마루 부리 · 본명조 Bold)로 바꾸기를 권한다.
- 사진에 촬영 정보(EXIF: 조리개 · 카메라)가 지워져 있어 넣지 못했다. 대신 **사진에서 직접 잰 색**을 썼다. 조리개 · 카메라 · 장소를 알려 주면 03쪽 레터링에 넣는다.
- 때(DUSK · DAY …)는 사진을 보고 적은 것이다.
