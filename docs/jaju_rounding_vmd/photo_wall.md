# 사진 벽 (단일 쪽) — 기존 안 + 조합이 다른 세 안

작성일: 2026-10-22. 사례: 사용자가 보낸 사진가의 모자이크 포트폴리오 한 장(검정 바탕 · 가는 틈 · 꽉 찬 세 줄 · 크기가 다른 덩어리 · 왼쪽 위 글 한 칸).
재료: 지원자의 사진 PH-01–17 · 건축 AR-01–10 · 착장 FA-01–05, 32장 모두 한 번씩 + 글 한 칸(02 Observe 문장). 표지 · 책 사진은 출처 확인 전이라 뺐다.

| 판 | 파일 | 조합 원리 |
|---|---|---|
| 기존 | `layout/photo_wall.pdf` | 사례 그대로 — 세 줄, 줄마다 큰 한 장 · 2×2 · 세로 쌓기를 섞음 |
| 안 A · 색과 시간 | `layout/photo_wall_options.pdf` 1쪽 | 가로 세 줄을 빛으로: 밤 · 흑백 / 낮 · 흰 모형 · 파란 바다 / 노을 · 따뜻한 실내 |
| 안 B · 기둥과 띠 | 같은 파일 2쪽 | 세로 기둥 여섯을 무엇을 찍었나로(사람 셋 · 건축 둘 · 밤 하나), 아래 띠 하나에 풍경 여덟 |
| 안 C · 큰 한 장과 둘레 | 같은 파일 3쪽 | 가운데 카누(PH-03)를 쪽의 약 1/3 크기로, 위 · 아래 띠와 양쪽 기둥이 둘러쌈 — 크기 대비 |

만드는 법: `python3 tools/jaju_layout/photo_wall.py` · `python3 tools/jaju_layout/photo_wall_options.py`.

## 결정 (2026-10-22)

사용자: "레이아웃은 A안으로 보류한다. 이후 작업한다." → 사진 벽은 **안 A · 색과 시간**을 잠정안으로 두고, 들어갈 자리 · 다듬기는 다음 작업에서.
