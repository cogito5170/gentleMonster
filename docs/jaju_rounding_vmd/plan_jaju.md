사용자: "B10 은 기존 안으로 유지한다. 자주 홈페이지의 이미지 및 기사이다. '기존 안'을 자주가 추구하는 스타일에 맞도록 변형.

## 4. 가져오지 않은 것 · 남은 것

- 자주 로고 · 자주의 사진 — 쓰지 않는다(W2-D25). 로고 자리에는 `FROM THE INSIDE` · `/01 OBSERVE`.
- **손 그림 낙서**(칫솔 · 드라이기 · 새 · 다람쥐 · 실타래)와 **종이 질감** — 새 이미지라 이 세션에서 그리지 않는다(CLAUDE.md). 필요하면 `codex-image` 스펙으로 Codex 에 맡긴다.
- 한글 굵은꼴이 이 환경에 없어 획을 더해 굵게 보이게 했다. 최종본은 Pretendard(자주의 둥근 고딕에 가까움) Bold 로.
- 영상 칸 — 영상이 없다.
- 표지 사진 출처(W2-O22) · 자기 소개 빈칸(W2-O23)은 그대로.
