## 사례 3 · NEA MAGAZINE ISSUE N.3 — RIVISTA

**맥락 (첫 화면 소개 문단):** 사진과 문학의 관계를 다루는 잡지. 이번 호의 주제는 **비장소(non-places, nonluoghi)** — 인류학자 마르크 오제(Marc Augé)의 개념. 이탈리아 · 미국 · 독일 · 네덜란드 · 팔레스타인의 사진 프로젝트 다섯 편, 각 사진에서 출발한 미발표 이야기. 소개는 영어 · 이탈리아어 두 언어.

### 순서

| # | 무엇 | 레이아웃 |
|---|---|---|
| 1 | 여는 이미지 + 소개 | 검정 바탕, 잡지를 손에 든 사진(초록빛) + 가운데 좁은 단의 소개 글 (EN · IT) |
| 2 | 표지 | 연어색 표지, 세리프 `NEA MAGAZINE` · `ISSUE N.3` · 아래 `NONLUOGHI` |
| 3 | 판권 + 목차 | 왼쪽 좁은 판권 단, 오른쪽 목차: EDITORIALE 4 · CIVIL WAR 13 · NON POSSO FARE A MENO DI SCRIVERTI 35 · IL RE CAVALCA NELLA NOTTE 55 · STUDIO SULLE CASE NEL BOSCO 75 · NUR E LA FRAGILITÀ DELL'ISTANTE 93 · EXTRA 108. 큰 세리프 제목 + 작은 저자명 + 쪽 번호 |
| 4 | 편집장 글 | 초록 제목 `EDITORIALE`, 2–3단 본문, 초록 글자 |
| 5 | **도해 사이 면** | 흰 바탕에 초록 가는 선의 삼각형: RITRATTO(초상) · VOCE(목소리) · IMPERMANENZA(덧없음) |
| 6 | 손에 든 사진 | 초록빛으로 찍은 펼침면 — CIVIL WAR · IMMAGINE ACUSTICA · CONCETTO |
| 7 | 장 1 여는 면 | 왼쪽 빨간 톤 사진(창), 오른쪽 저자 둘 + 세리프 대형 제목 `CIVIL WAR` |
| 8–10 | 장 1 본문 | 2단 본문 사이 작은 빨간 사진들 → 사진 펼침면 → 흰 면에 작은 사진을 흩어 놓은 펼침면 |
| 11 | 도해 사이 면 | 문장 구조도: SN · SV · SP · Art. · N. · V. → `LA VITA È L'ESITO DI UNA STORIA`(삶은 이야기의 결과다) |
| 12 | 장 2 여는 면 | 흑백 기록 보관 선반 사진 + `NON POSSO FARE A MENO DI SCRIVERTI` |
| 13–15 | 장 2 본문 | 사물 · 기록물 사진 콜라주(크기 다른 사진 여러 장), 본문 |
| 16 | 도해 사이 면 | 손에 든 사진 → 같은 면을 평면으로: FAMIGLIA → FERITA → segno → NOI |
| 17 | 장 3 여는 면 | 흑백 숲 + 집 사진, `STUDIO SULLE CASE NEL BOSCO` |
| 18 | 장 3 본문 | 작은 흑백 사진 + 본문 |
| 19 | 도해 사이 면 | COSE VISIBILI / COSE INVISIBILI · LUOGO/OGGETTO · intelligenza / sogno / volontà |
| 20 | 장 4 여는 면 | 어두운 바위 사진, `IL RE CAVALCA NELLA NOTTE` |
| 21–22 | 장 4 본문 | 본문 → 어두운 사진 양면 (밤하늘의 흰 새) |
| 23 | 도해 사이 면 | 원과 사선: segno · IMMAGINE ACUSTICA · CONCETTO |
| 24 | 장 5 여는 면 | 작은 사진 + `NUR E LA FRAGILITÀ DELL'ISTANTE` |
| 25–27 | 장 5 본문 | 본문 → 픽셀이 깨진 사진들 → 손에 든 사진 |
| 28 | 끝 | 초록 세로 글자 `NABIL BEY SALAMEH` + 본문 |

### 흐름

- **장마다 같은 순서:** 도해 사이 면(초록 선) → 여는 면(사진 + 저자 + 세리프 제목) → 본문(글 + 작은 사진) → 사진 펼침면. 다섯 장이 같은 틀로 되풀이돼, 내용이 바뀌어도 넘기는 리듬이 같다.
- **도해가 장과 장을 나눈다.** 사진이 아니라 **생각(개념)** 으로 다음 장을 연다: 삼각형 · 문장 구조도 · 화살표 · 원. 단어 셋이나 넷이 선으로 이어져 그 장이 무엇에 대한 것인지 먼저 보인다.
- **장마다 사진의 색이 다르다:** 빨강(Civil War) → 흑백 기록물 → 흑백 숲 → 어둠 → 픽셀 깨짐. 종이(흰색) · 글자(검정) · 강조(초록)는 끝까지 같고, 사진만 바뀐다.
- **보여 주는 방식이 둘:** 평면 펼침면(정보)과 손에 든 사진(분위기, 초록빛)이 번갈아 나온다. 책이라는 **물건**을 보여 준다.

### 레이아웃

| 항목 | 규칙 |
|---|---|
| 종이 · 색 | 흰 종이, 검정 글자, 강조색 초록 하나. 사진이 유일한 다른 색 |
| 글자 | 제목 = 세리프 대문자, 행간이 좁다. 본문 = 세리프 2단 양쪽 맞춤. 저자명 · 판권 = 작은 산세리프 |
| 여는 면 | 왼쪽 사진(전면 또는 여백 안), 오른쪽 위에 저자 둘, 가운데에 제목 — 오른쪽 면 대부분이 비어 있다 |
| 도해 | 가는 초록 선 + 초록 세리프 단어. 펼침면 전체를 하나의 도면처럼 쓴다. 가운데 접는 선을 넘는다 |
| 작은 사진 | 본문 가장자리나 빈 면에 작게, 흩어 놓는다. 큰 사진은 사진 펼침면에서만 |
| 바깥 여백 | 세로로 쓴 머리말 · 쪽 번호 (ETÉREO 와 같다) |

## 사례 4 · SKATE FASHION HISTORY — ZINE (Victoria Skolimowska, Behance)

**맥락:** 스케이트보드 패션의 역사를 1960년대부터 지금까지 시대별로 정리한 진(zine). 서브컬처가 거리 패션 · 주류 패션이 되는 과정과, 그 결과 생긴 질문(전유인가 존중인가)까지.

### 순서

| # | 제목 (펼침면의 큰 글자) | 시대 · 내용 | 레이아웃 |
|---|---|---|---|
| 0 | SKATE FASHION | 표지 | 빨강 바탕, 콜라주 |
| 1 | PEACE. LOVE. SKATE. | 여는 면 | 사진 콜라주 + 체크무늬 + 빨간 낙서, 세 낱말을 펼침면에 흩어 |
| 2 | ASPHALT SURFERS | 1960s | 왼쪽 타자기체 본문, 오른쪽 사진 콜라주. 제목을 접는 선 양쪽으로 나눔 |
| 3 | GET TRICKS OR DIE TRYING | — | 세로로 돌린 대형 제목 + 체크무늬 위 사진 |
| 4 | Z-BOYS | 1970s | 세로 제목, 사진 · 인용구 박스 |
| 5 | the skate shoe | — | 빨강 · 파랑 조각 위에 신발 사진을 흩음, 손 글씨 낙서 |
| 6 | VANS — A CULT SHOE FOR A SUBCULTURE | — | 체크무늬 테두리, 신발 클로즈업 |
| 7 | THE THRASHER ERA / SKATE AND DESTROY | 1980s | 검정 · 빨강 큰 블록, 잡지 표지 같은 콜라주 |
| 8 | STREET CULTURE | 1990s | 제목을 접는 선 양쪽으로, 흑백 거리 사진 |
| 9 | THE MTV ERA | 2000s | 검정 위 대형 `MTV`, 세로 인용 박스 |
| 10 | STREET STYLE. SKATE STYLE. | — | 두 문장을 대각선으로 나눠 놓음, 인물 사진 |
| 11 | APPROPRIATION OR APPRECIATION? | 질문 | 위아래로 나눈 제목 사이에 인물 한 명, 오른쪽 무리 사진 |
| 12 | SKATE FASHION TODAY | 지금 | 원형으로 자른 사진 + **아이템 라벨**(Baggy jeans · Bucket hat · Vans · Sneakers · Big tees and hoodies · Bomber jackets) + 문장 `Just skate. There are no rules in skateboarding.` · `Freestyle.` · `No limits.` |
| 13 | THE SKATEBOARD STATEMENT | 끝 | 보드 · 무리 사진을 세로 띠로 잘라 이어 붙임, 검정 낙서 |
| — | 썸네일 격자 | 전체 펼침면 4열 요약 | |

### 흐름

- **연대기:** 1960s → 1970s → 1980s → 1990s → 2000s → 지금. 시대를 여는 펼침면마다 연도가 작게 붙는다. 시대 사이에는 사물 하나(신발 · Vans)나 구호(GET TRICKS OR DIE TRYING)를 다루는 펼침면이 끼어 속도를 바꾼다.
- **끝은 질문 → 지금 → 선언.** 역사를 다 말한 뒤 "전유인가 존중인가?"를 묻고, 지금의 스타일을 아이템 단위로 풀고, `Statement` 로 닫는다.
- **같은 재료, 다른 구성:** 모든 펼침면이 같은 네 색(연어색 · 빨강 · 파랑 · 검정)과 같은 사진 처리(하프톤 2도)를 쓴다. 바뀌는 것은 배치뿐이다.

### 레이아웃

| 항목 | 규칙 |
|---|---|
| 색 | 연어색 바탕 + 빨강 · 파랑 · 검정. 사진은 모두 빨강 또는 파랑 한 색 하프톤 — 출처가 다른 사진을 하나의 톤으로 묶는다 |
| 글자 | 제목 = 아주 좁은 굵은 산세리프(콘덴스드), 화면을 가득 채운다. 본문 = 타자기체(고정폭) 작은 글. 손 글씨 라벨 |
| 제목 | 접는 선 양쪽으로 나누거나(ASPHALT / SURFERS, STREET / CULTURE), 세로로 돌리거나, 위아래로 나눠 그 사이에 사진을 끼운다 |
| 사진 | 찢은 종이처럼 잘라 겹친다. 원형 마스크, 세로 띠 |
| 장식 | 체크무늬(Vans), 빨간 · 검정 낙서, 점선 윤곽 — 스케이트 문화의 표지 |
| 주석 | 사진 속 옷 · 소품에 화살표와 손 글씨 이름 (SKATE FASHION TODAY) |

## 두 사례를 나란히

| | 사례 3 NEA | 사례 4 Skate zine |
|---|---|---|
| 무엇 | 사진 + 문학 잡지 한 호 | 패션사 진 |

| 공통 | 같은 틀을 장마다 되풀이해 리듬을 만든다. 제목이 접는 선을 넘거나 양쪽으로 나뉜다 | |

## JAJU 포트폴리오에 가져올 것 (제안)

| 사례 | 가져올 것 | 어디에 |
|---|---|---|
| 3 | **장을 여는 개념 도해** — 가는 선 + 단어 셋: 관찰 → 담다 → 채우다. JAJU 의 점선 틀 · 뷰파인더와 같은 언어 | 장 2(건축) · 장 3(패션) 앞의 사이 면. 장 1 앞에도 하나 두면 세 장이 같은 틀이 된다 |
| 3 | 여는 면 = 왼쪽 사진 + 오른쪽 넓게 빈 면에 제목 | 장 2 · 3 의 여는 면 (장 1 2쪽과 맞추기) |
| 3 | 장마다 사진의 톤을 다르게, 바탕 · 글자 · 강조색은 같게 | 사진(컬러 필름) → 건축(흑백 도면) → 패션(컬러) |
| 4 | **아이템 라벨 주석** — 사진 속 옷에 가는 선 + 이름 | 장 3 패션의 '착장 분해' 면 (10쪽) |
| 4 | 같은 사진 처리로 출처가 다른 사진을 묶기 | 패션 사진의 촬영 조건이 다르면 한 톤으로 맞추는 방법으로 (선택) |
| 4 | 끝을 질문 → 지금 → 선언으로 | 제안 · 닫는 면: "자주 쓸수록"에 대한 나의 답 |

가져오지 않을 것: 사례 4 의 낙서 · 찢은 종이 · 시끄러운 색. 표지 B안(검정 · 조용함)과 JAJU 의 생활 · 일상 톤에 맞지 않는다.
사례 3 은 흰 종이인데 B안은 검정 바탕이다 — 도해를 검정 위 흰 · 회색 선으로 옮기면 같은 효과를 낼 수 있다.
