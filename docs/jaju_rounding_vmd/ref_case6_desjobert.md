## 1. 흐름

```
표지 PORTFOLIO          옅은 회색 위 분홍 번짐, 굵은 산세리프 한 낱말 + 이름
Hello!                 큰 회색 유령 글자 'Hello' 위에 'Hello!', 'I'm …', 소개 3줄 | 오른쪽 사람 사진(배경 없이)
Resume.                Education · Skills(아이콘) | Experiences(회사 · 기간 · 한 줄)
목차                    프로젝트 4개: 이름 · 한 줄 · 가는 선 · 쪽 번호
/01 Japan Airline.      어두운 실내 렌더 전면 + 빗금 번호 · 마침표 제목 · 한 줄 · 짧은 문단
  → 맥락(제목 + 문단 + 스케치) → 부분 카드 3장(Lampe · Door · Console) → 특징(반투명 글 상자가 렌더 위에)
  → CMF 보드(재료 · 색 견본 + 영감 사진) → 사진 격자 → 전면 렌더 2–3장
/02 Matvänlig.          (IKEA × Barilla 냄비) 전면 → 브랜드 · 서체 · 색 → 그래픽 차터 → 패키지 → 특징(Passive cooking.) → 반투명 상자 → 디테일 → 생활 장면
/03 Monolith.           (커피 머신) 전면 → 개념 → 도면(left · front · right) → 반투명 상자(Coffee flow) → 손에 든 장면 → 분위기 전면
/04 Lambda light.       (조명) 전면 → 아이디어 스케치 → 사용법 도식(Dim the light · Adjust the height) → 디테일 셋 → 패턴 전면(주황) → 반투명 상자
Thank you.              유령 글자 위 'Thank you.' | Contact
```

**구조: 사람 → 목차 → 프로젝트 넷(같은 틀 되풀이) → 인사.** 프로젝트마다 순서가 거의 같다:
무드 전면(여는 면) → 무엇 · 왜(글 + 스케치) → 부분 · 재료(카드 · CMF) → 특징 하나(반투명 상자) → 사진으로 끝(전면 2–3장).

## 2. 텍스트

- 쪽마다 **제목 한 줄 + 문단 2–4줄**. 긴 글이 없다.
- 제목은 굵은 산세리프, **마침표로 끝난다**(`Resume.` `Japan Airline.` `Passive cooking.` `Thank you.`).
- 프로젝트 번호는 **빗금 + 두 자리**(`/01` `/02`), 얇고 크게, 제목 왼쪽 위.
- 카드 · 도면의 라벨은 한 낱말(Lampe · Door · left · front · right).

## 3. 이미지 배치 · 레이아웃

| 장치 | 어디 | 효과 |
|---|---|---|
| 전면 렌더 | 프로젝트마다 3–5쪽 | 쪽의 절반 이상이 사진만 — 무드가 먼저 |
| 유령 글자 | Hello · Resume · Thank you | 큰 회색 외곽 글자 위에 같은 낱말 — 빈 면을 장식 없이 채움 |
| 반투명 글 상자 | 프로젝트마다 한 번 | 사진 위에 흰 반투명 상자 + 제목 + 문단 — 글과 사진을 한 면에 겹침 |
| 카드 3장 | 부분 설명 | 같은 크기 세로 카드, 위에 라벨 · 오른쪽 위 작은 번호 |
| CMF 보드 | 재료 · 색 | 실물 견본을 비스듬히 겹쳐 + 영감 사진 하나 |
| 도식 | 사용법 · 도면 | 회색 선 그림 + 한 낱말 라벨 |
| 바탕 | 대부분 옅은 회색 | 사진만 색을 가진다. 사이사이 어두운 전면이 리듬을 만든다 |
| 가장자리 | 쪽 왼쪽 세로 작은 글자 | 쪽 번호 · 프로젝트 표시 |

## 6. 따라가지 않은 것

- 옅은 회색 바탕 — 전체 톤은 B2(어두운 바탕)로 정해져 있다.
- 파트마다 전면 3–5쪽 — 10MB 한도와 사진 해상도(긴 변 1500px 안팎) 때문에 전면은 파트마다 1–2쪽에 그쳤다.
- 손 스케치 · CMF 실물 견본 — 재료가 없다. 있으면 파트 2(건축 스케치) · 파트 3(원단 견본)에 넣을 자리다.
