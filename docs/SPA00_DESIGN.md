## 판매되는 잡지처럼 — 표지

풀블리드 사진 위의 제호, 호수와 계절(Issue 00 — Autumn 2026), 커버라인 다섯 줄과 쪽 번호, 바코드 칸. **바코드는 'SPA-00' 만 담은
Code 39 이고 'Concept issue · Not for sale' 이라고 적었다** — ISSN · 가격 같은 실재처럼 보이는 기록은 만들지 않는다. 안쪽 접기 쪽 번호 옆에
'SPA — Autumn 2026'. 사진에는 고운 필름 그레인. 화면 표시용 사본은 Lanczos 로 2배 다시 표본화해 계단 현상을 없앴다 — 인쇄 해상도는 여전히
**원본 픽셀**로 잰다(첫 판은 측정용 썸네일 폭 1000 px 를 원본으로 착각해 해상도를 낮게 쟀다 — 테스트가 잡았다).

## 기법 — 찾아서 쓴 것

기법은 사용자의 카탈로그에서 찾았다: `magazine_urls_web.html` 의 29개 잡지가 가진 레이아웃 · 타이포그래피 · 이미지 · 색상 낱말(빈도 포함,
spec 의 `technique_vocabulary`). 거기에 VISUAL INDEX 의 처리와 몇 가지 고전 기법(편집자 추가라고 밝혔다)을 더했다. 29개를 지면에 실제로 썼고,
기법마다 `data-technique` 로 표시해 QA 가 어느 쪽에 있는지 센다. 목록과 출처와 쪽은 21쪽 'Techniques' 에, 데이터는 `techniques.json` 에.

쓰지 않은 것도 적었다: 디돈 세리프 · 고대비 획(글꼴이 없다 — 흉내 내지 않는다), 셀러브리티 커버 · 스튜디오(사진의 성격과 다르다),
모노그램 마스트헤드 · 핸드레터링(제호 SPA 는 사용자가 확정했다).

### 만들면서 잡은 것

- `background-clip:text` 로 사진을 채운 STOP 은 PDF 에서 글자 상자 가장자리에 가는 선이 남았다 → SVG 패턴 채움으로 바꿨다.
- 표지의 difference 혼합 제호는 사진 위에서 탁한 보라 회색이 됐다 → 종이색 단색으로.
- 표지 텍스트가 휴대폰에서 겹쳤다(겹침 검사가 잡았다) → 휴대폰에서는 사진을 배경으로 두고 글을 흐름으로 쌓는다.

## QA 가 못 보는 것 — 사람이 볼 자리

- 사진을 고른 판단 자체(표지가 정말 가장 젠틀몬스터다운가). 렌즈 쪽 근거는 전부 검색 조각 수준이다.
