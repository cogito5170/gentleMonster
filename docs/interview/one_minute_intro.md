## 원고

**[현재 · 약 8초]**
안녕하십니까. 건축에서 배운 공간감과 패션에 대한 안목을 갖춘, JAJU 라운딩 VMD 지원자 정혁주입니다.

**[경험 · 약 32초]**
저는 있는 것의 자리를 다시 정해 공간을 바꾸는 데 강점이 있습니다. 베이글 카페 아르바이트 때, 지하 창고에 구분이 없어 물건을 찾는 데 시간이 걸렸습니다. 부모님 의류 회사의 수납 방식을 떠올려 사장님께 먼저 정리를 제안했고, 1주 반 동안 박스로 품목마다 칸을 나눴습니다. 그 뒤로 물건을 찾는 시간이 줄었고, 사장님은 발주 때 남은 수량을 바로 확인하게 됐습니다. 새로 산 것 없이, 나누고 다시 놓기만 한 결과였습니다.

**[연결 · 약 17초]**
라운딩 VMD는 매장마다 브랜드의 기준을 같은 모습으로 맞추는 일이라고 생각합니다. 매장마다 공간을 먼저 읽고, 옷을 즐겨 입으며 기른 스타일링 감각으로 착장을 맞춰, 어느 JAJU 매장에서든 같은 장면을 만들겠습니다. 감사합니다.

- 분량: 공백 포함 430자, 한글 293음절 — 보통 말빠르기(초당 4.8~5.5음절)로 약 53~61초. 실제로 소리 내어 재고, 넘치면 경험의 마지막 문장부터 줄인다.

## 이렇게 짠 이유

| 가이드 기준 | 원고에서 |
|---|---|
| 현재: 직무 + 수식어 한 줄 | Q1 · CV 와 같은 정체성 문장. 성장 배경('어릴 때부터')은 빼고 바로 강점으로 |
| 경험: S · T 짧게, A · R 에 비중 | 상황 한 문장 → 행동 두 가지(먼저 제안 · 1주 반 칸 나누기) → 결과 두 가지(찾는 시간 · 발주 때 수량 확인) |
| 수치화 | 서류에 있는 '1주 반'만. 없는 퍼센트 · 시간은 만들지 않음 |
| 나만의 표현 | '새로 산 것 없이, 나누고 다시 놓기만' (Q3) — 진열의 일과 같은 말 |
| 신입은 태도 | '먼저 제안' — 시키지 않은 일을 스스로 한 점 |
| 연결: 회사 · 직무와 잇기 | Q2 직무 정의 + 소제목 '어느 매장에서든 같은 장면' |
| 서류와 이어짐 | 정체성(Q1) · 경험(Q3) · 직무 정의(Q2) — 세 문항이 한 번씩 |
| 공고와 맞춤 | 업무 '진열 및 환경 개선', 자격 '패션 스타일링 가능', 우대 '알바 포함 진열 경험' |

## 외우지 말고 이 키워드만

1. 공간감 + 패션 안목 → JAJU 라운딩 VMD 정혁주
2. 강점: 있는 것의 자리를 다시 정한다
3. 베이글 카페 지하 창고 — 구분 없음 → 찾는 데 오래
4. 의류 회사 방식 → 먼저 제안 → 1주 반, 박스로 칸
5. 찾는 시간 ↓ · 발주 때 수량 바로 → 새로 산 것 없음
6. 매장마다 같은 기준 → 공간 읽기 + 스타일링 → 같은 장면

## 바꿔 쓸 줄 (면접 분위기에 따라)

- 회사 이해를 더 보이려면, 연결 첫 문장 앞에: 'JAJU 가 리브랜딩 첫 매장에서 동선과 구성을 고객 눈높이에 맞췄듯,' (Q1 · Q2 근거, 보도자료 2024-12-23) — 약 5초 늘어난다.
- 출장 · 장기 근무를 직접 말하려면, '감사합니다' 앞에: '출장이 많은 현장에서도 오래 함께하겠습니다.' (Q1) — 약 4초.
- 둘 중 하나를 넣으면 경험의 마지막 문장을 빼서 1분을 지킨다.
