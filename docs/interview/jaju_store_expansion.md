# JAJU 매장은 지금 늘고 있는가 — 매장 추세 조사

조사일: 2026-10-27. 방법: 웹 검색 결과에 실린 기사 문장(인용)을 모았다. 이 환경의 네트워크 정책으로 기사 원문 페이지는 열지 못했다 —
숫자는 검색 결과가 인용한 원문 문장 기준이며, 면접에서 쓰기 전에 원문을 한 번 열어 확인한다(⚠ 표시는 특히 확인 필요).

## 결론

- **전체 매장 수는 2023년을 정점으로 줄었다**: 261개(2023 말) → 249개(2024 3분기) → 247개(2024 말) → 246개(2025 인수 시점). 저효율 매장 정리.
- **2026년부터는 '새 형태 매장'으로 다시 늘리는 단계**: 신세계까사로 옮긴 뒤(2026-01-01) 생활밀착형 **콤팩트 매장을 연내 20개 추가, 2030년까지 100여 개**로 늘릴 계획(2026-02 보도). 패션 특화 압구정로데오점 신규 오픈(2026-06-04).
- 그러므로 '매장 수가 늘고 있다'보다 **'매장을 정리하고, 새 형태로 열고 바꾸는 중'**이 정확하다 — 라운딩 VMD 의 '매장 오픈 / 리뉴얼 업무 지원'이 많은 시기.

## 4. 서울경제 2026-02-23 원문 요점 (사용자 제공, 확인 ✅)

| 항목 | 원문 |
|---|---|
| 전략 | 그간 대형마트와 역세권 중심 출점 → 대형 아파트단지 등 주거지역에서 신규 수요 |
| 목표 | 콤팩트형 매장 연내 20개까지 오픈, 2030년까지 100여 개 |
| 형태 | 50평 안팎 소형 매장, 근린 수요를 반영한 패션 · 리빙 중심 생활 필수 상품군을 전략적으로 배치 |
| 현재 | 압구정 · 서초 · 염창 · 분당 수내 4개 매장 운영 중, 순항 |
| 성과 | 압구정 · 서초 · 분당 수내점, 오픈 한 달 만에 자주 전체 매장 월 평균 매출의 50%를 웃돎 (회사 측) |
| 그룹 시너지 | 자주 매장을 찾는 고객이 신세계까사 가구에도 관심을 갖도록 — 건설 경기 침체로 가구 실적이 부진한 상황 |
| 상품 협업 | 신세계까사 매트리스 + 자주 파자마 → 수면 시장 동시 공략 (관계자) |
| 배경 | 신세계까사가 지난해 말 신세계인터내셔날로부터 자주 사업부문 양수 |

라운딩 VMD 에 주는 뜻 (해석)
- 매장 오픈 업무가 실제로 많아진다 — 연내 20개는 한 달에 한두 곳 꼴.
- 50평 안팎의 작은 매장에 '패션 · 리빙 생활 필수 상품군을 전략적으로 배치' — 좁은 면적에서 무엇을 어디에 둘지가 핵심. 실측 · 3D 로 배치를 미리 확인하는 역량과 바로 닿는다.
- 매장마다 입지(아파트단지 · 역세권 · 패션 상권)가 달라 같은 기준을 매장 크기에 맞춰 옮기는 일 — 라운딩의 일.
- 면접 질문 거리: 가구(까사미아) 판촉과의 시너지, 수면(파자마 + 매트리스) 연출.

## 면접에서 쓸 때

- 쓸 수 있는 말: '콤팩트 매장을 2030년까지 100여 개로 늘릴 계획', '압구정로데오점처럼 패션을 강화한 새 매장', '리브랜딩 매장'.
- 쓰지 않는 말: 정확한 현재 매장 수(2026 공개 수치 없음), 비공식 행사 페이지의 매장들, 까사미아 결합(검토 단계).
- 확인할 것: 2024 말 247 · 2025 246 의 출처 매체. 콤팩트 매장의 '압구정'(2026-02 이미 운영)은 6월 4일에 연 압구정로데오점과 다른 매장으로 보인다(날짜로 추정).
- 서울경제 2026-02-23 은 원문 확인 완료(사용자 제공).
