# 자기소개서 제작 절차

시작하기 전에 `docs/portfolio/PROCESS.md`를 처음부터 끝까지 읽고 그 순서대로 진행한다. 세션 운영 형식은 `docs/portfolio/agent_protocol.md`를 따른다.

꼭 지킬 것 (PROCESS.md §0 요약):
- 사실·경험·수치·동기·감정은 지어내지 않는다. 막히면 사용자에게 묻는다.
- 합니다체, 지칭어 없음, 막연한 다짐 없음, 한 문장 한 생각.
- 통째로 다시 쓰지 않는다. 서로 다른 유형의 대안 3~5개를 주고 사용자가 고른다. 사용자가 준 문장은 그대로 반영한다.
- 글자 수는 공백·줄바꿈 포함 `len()`. 반영할 때마다 전문과 글자 수를 보여 준다.
- 모든 판과 선택은 `docs/portfolio/handoff/selection_*.json`의 `edits`에 남긴다.
